# 小国開放経済モデル 設計方針

> **Phase 3 / P2**
> 関連Issue: #47

---

## 1. 背景と目的

DME は現在、閉鎖経済モデル（IS-LM・AD-AS・New Keynesian・Ramsey・RBC）を中心に実装している。
AIエコノミストとして現実のマクロ環境を分析するには、為替レート・海外金利・外需・純輸出を扱う
**開放経済モデル**への拡張が必要である。

本ドキュメントは、Phase 3 において最初に実装すべき小国開放経済モデルを選定するための設計方針メモである。
実装そのもの・実データ取得・為替予測モデルの構築は対象外とする。

---

## 2. 候補モデルの概要

### 2.1 Mundell-Fleming モデル

IS-LM を開放経済に拡張した標準フレームワーク。
財市場（IS）・貨幣市場（LM）・国際収支（BP）の3市場同時均衡を扱う。

小国仮定（world interest rate `r*` は外生）と資本完全移動を前提とすると、
- **固定為替相場制**: 金融政策は無効、財政政策は完全有効
- **変動為替相場制**: 財政政策はクラウドアウトされ無効、金融政策は完全有効

という「Mundell-Fleming定理」が成立する。

**構造方程式**:

```
IS: Y = C(Y-T) + I(r) + G + NX(e)
LM: M/P = L(Y, r)
BP: NX(e) + CF(r - r*) = 0   （小国・変動相場 → r = r*）
```

### 2.2 開放経済IS-LM（Mundell-Fleming の変形）

Mundell-Fleming と本質的に同じ枠組みだが、資本移動を不完全とする場合や
BP曲線の傾きを可変とするバリアントを含む総称。
DME では Mundell-Fleming と統一的に扱う。

### 2.3 開放経済AD-AS

Mundell-Fleming に総供給曲線（SRAS/LRAS）を加えたモデル。
物価 `P` を内生化し、需要ショックと供給ショックの両面を扱える。

| 追加できる分析 | 内容 |
|---|---|
| 為替レートと物価の相互作用 | 為替レート変化がインポートコスト経由で物価に波及 |
| スタグフレーション的状況 | 外需ショック + 供給ショック同時分析 |

ただし AS 曲線の定式化（価格硬直性の程度）が複雑になりやすい。

### 2.4 開放経済New Keynesian

3方程式モデル（IS・NKPC・Taylor Rule）を開放経済に拡張したもの。
主要な拡張要素:

- IS曲線: 為替レートを通じた外需の影響を追加
- NKPC: 輸入価格を通じた為替パス・スルー効果
- UIP（非カバー金利平価）: 内外金利差と期待為替変動の関係

Galí & Monacelli (2005) が小国開放経済NK の標準的定式化を与えている。

## 3. 候補モデルの比較表

| 項目 | Mundell-Fleming | 開放経済AD-AS | 開放経済NK |
|---|---|---|---|
| **分類** | 静学 | 静学 | 動学（前向き期待） |
| **物価** | 固定 | 内生（SRAS） | 内生（NKPC） |
| **為替レート** | 内生 | 内生 | 内生（UIP） |
| **海外金利ショック** | ○ | ○ | ○ |
| **外需ショック** | ○ | ○ | ○ |
| **為替パス・スルー** | 部分的 | △ | ○ |
| **期待形成** | なし | なし | 合理的期待 |
| **既存ISLMとの接続** | 直接拡張 | 拡張あり | 独立定式化 |
| **実装複雑度** | 低 | 中 | 高 |
| **標準教科書** | Mankiw, Krugman | Romer | Galí (2008) |
| **AIエコノミスト向け解釈** | 容易 | 中程度 | 難（線形化前提） |

## 4. 扱いたい問いの整理

| 問い | 対応するシナリオ |
|---|---|
| 国内金融政策（利上げ）の為替への影響 | `r` 上昇 → 資本流入 → `e` 増価（自国通貨高） |
| 海外金利（`r*`）上昇ショック | `r*` 上昇 → 資本流出 → `e` 減価（自国通貨安）→ NX 改善 → Y 変化 |
| 外需ショック（貿易相手国景気後退） | `NX` 外生的減少 → IS 曲線左シフト → Y 低下 |
| 純輸出と産出の関係 | `e` 減価 → `NX` 改善 → `Y` 増加（Marshall-Lerner条件下） |
| 財政拡張の有効性と為替制度 | 変動相場: クラウドアウト、固定相場: 乗数効果あり |

これらの問いはすべて **Mundell-Fleming** の枠組みで直接分析できる。

## 5. 変数候補の整理

### 5.1 内生変数

| 変数 | 記号 | 説明 |
|---|---|---|
| 実質産出 | `Y` | 実質GDP |
| 名目利子率（国内） | `r` | 国内短期金利（変動相場制では `r = r*`） |
| 為替レート | `e` | 名目為替レート（高いほど自国通貨安） |
| 純輸出 | `NX` | 輸出 − 輸入 |
| 消費 | `C` | 家計消費 |
| 投資 | `I` | 民間投資 |

### 5.2 外生変数・政策変数

| 変数 | 記号 | 説明 |
|---|---|---|
| 海外金利 | `r*` | 世界利子率（小国仮定で外生） |
| 政府支出 | `G` | 財政政策変数 |
| 税 | `T` | 定額税 |
| マネーサプライ | `M` | 金融政策変数 |
| 物価水準 | `P` | 短期固定（Mundell-Fleming） |
| 海外物価 | `P*` | 海外物価水準（実質為替レートの計算に使用） |

### 5.3 派生変数（分析補助）

| 変数 | 記号 | 計算式 |
|---|---|---|
| 実質為替レート | `q` | `q = e * P* / P` |
| 国際収支 | `BP` | `NX + CF（資本収支）` |

## 6. 最小実装モデルの選定

### 選定: **Mundell-Fleming モデル（変動相場制・小国・完全資本移動）**

#### 選定理由

1. **既存IS-LM実装との連続性**: `ISLMModel` を直接拡張する形で実装できる。`NX(e)` 項の追加と `r = r*` 条件が主な差分であり、スコープが明確。

2. **問いのカバー率**: §4 で整理した主要な問いを静学モデルとして完結に分析できる。

3. **実装複雑度が低い**: 連立方程式の解析解または数値解が得やすく、Juliaの `NLsolve` との相性も良い。

4. **AIエコノミスト向け解釈が容易**: 為替・金利・政策の因果を図示しやすく、LLMが説明テキストを生成しやすい。

5. **拡張路線が明確**: Mundell-Fleming → 開放経済AD-AS → 開放経済NK という自然な拡張ステップがある。

#### 見送りとした候補

| モデル | 見送り理由 |
|---|---|
| 開放経済AD-AS | Mundell-Flemingの後続として実装する。物価内生化の追加スコープが大きい |
| 開放経済NK | 前向き期待・UIPの線形化が複雑。閉鎖経済NKの後続ステップとして位置づける |

## 7. 最小実装のスコープ

### 7.1 モデル構造

**小国・完全資本移動・変動為替相場制**の Mundell-Fleming モデルを基本とする。

```
IS:  Y = C(Y-T) + I(r) + G + NX(e)
LM:  M/P = l1*Y - l2*r
UIP/BP: r = r*  （小国・完全資本移動）
NX:  NX(e) = nx0 + nx1 * e   （線形近似）
```

パラメータ:
- IS-LM部分は `ISLMModel` のパラメータを継承
- 追加パラメータ: `r*`（海外金利）、`nx0`（自律純輸出）、`nx1`（純輸出の為替感応度）、`e0`（初期為替レート）

### 7.2 提供する機能

| 機能 | 内容 |
|---|---|
| `steady_state` | 均衡 `(Y*, r*, e*, NX*)` を返す |
| `simulate` | ベースライン均衡の1時点シミュレーション（`SimulationResult` 形式） |
| `mf_policy_shock` | ベースラインと政策後を比較（`islm_policy_shock` の開放経済版） |

### 7.3 対応するシナリオ

| シナリオ | 操作 |
|---|---|
| 財政拡張 | `G` 増加 → 変動相場制での為替増価とクラウドアウトを確認 |
| 金融緩和 | `M` 増加 → 為替減価と NX 改善を確認 |
| 海外金利ショック | `r*` 上昇 → 自国通貨安と NX 変化を確認 |
| 外需ショック | `nx0` 低下 → Y 低下と為替調整を確認 |

### 7.4 対象外（最小実装では扱わない）

- 固定為替相場制のシミュレーション（後続Issue）
- 不完全資本移動（BP曲線の傾きが有限なケース）
- 物価内生化（開放経済AD-ASへ）
- 前向き期待・UIP動学（開放経済NKへ）
- 実データとの接続・キャリブレーション

## 8. 実データ接続時の候補系列

実装後に実データと接続する際の候補系列をメモする。実データ取得は後続フェーズの対象。

### 8.1 日本

| モデル変数 | データ系列 | 公表機関 | 備考 |
|---|---|---|---|
| `Y`（産出） | 実質GDP（季節調整済み） | 内閣府・国民経済計算（SNA） | 四半期ベース |
| `r`（国内金利） | 無担保コール翌日物 / 10年国債利回り | 日本銀行 | 政策金利は誘導目標 |
| `r*`（海外金利） | FF金利 / 米国10年国債利回り | Fed / FRED: DFF, GS10 | 対米分析の場合 |
| `e`（為替レート） | USD/JPY 為替レート（月中平均） | 日本銀行 / FRED: DEXJPUS | 高いほど円安 |
| `NX`（純輸出） | 財・サービスの純輸出 | 財務省・国際収支統計 / SNA | SNA上は「財・サービス輸出−輸入」 |
| `M`（マネーサプライ） | M2（季節調整済み） | 日本銀行 | M3またはM1のケースも |
| `P`（物価） | 国内企業物価指数（CGPI）/ CPI | 日本銀行 / 総務省 | モデルではデフレーターとして使用 |

### 8.2 米国（比較用）

| モデル変数 | FRED系列ID | 説明 |
|---|---|---|
| `Y` | `A191RL1Q225SBEA` | Real GDP growth rate（四半期） |
| `r` | `DFF` | Effective Federal Funds Rate |
| `r*` | 米国が大国の場合は外生設定不可 | 対象国に応じて変更 |
| `e` | `DTWEXBGS` | Trade-weighted USD index |
| `NX` | `BOPGSTB` | Trade balance |
| `M` | `M2SL` | M2 money stock |

### 8.3 キャリブレーション指針

| パラメータ | キャリブレーション方法 |
|---|---|
| `nx1`（純輸出の為替感応度） | 輸出弾力性推定（Marshall-Lerner条件が成立するか確認） |
| `r*`（海外金利） | FF金利またはG7平均金利の時系列平均 |
| IS-LM部分 | 閉鎖経済IS-LMモデルのキャリブレーション方法を継承（後続フェーズ） |
