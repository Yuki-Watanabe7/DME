# Solow成長モデル

## 目的

Solow成長モデルは、長期的な経済成長と資本蓄積を分析するための基礎的なマクロ経済モデルです。
外生的な貯蓄率・人口成長率・技術進歩率のもとで、資本と生産がどのような定常状態に収束するかを示します。

Ramsey/RBCモデルとは異なり、家計の最適化問題を解きません。貯蓄率 `s` は外生パラメータとして与えられます。

## 変数

すべての変数は**効率労働単位あたり**（per-efficiency-unit）で表されます。

| 変数 | 説明 |
|------|------|
| `k`  | 効率労働単位あたり資本 (K / (A · L)) |
| `y`  | 効率労働単位あたり生産 (Y / (A · L) = k^α) |
| `c`  | 効率労働単位あたり消費 ((1−s) · y) |
| `inv`| 効率労働単位あたり投資 (s · y) |

## パラメータ

| パラメータ | 説明 | 典型値 |
|-----------|------|--------|
| `α`       | 資本分配率 | 0.3 |
| `s`       | 貯蓄率 | 0.2 |
| `δ`       | 資本減耗率 | 0.1 |
| `n`       | 人口成長率 | 0.01 |
| `g`       | 技術進歩率 | 0.02 |

## 定常状態

効率労働単位あたり資本の定常状態 k* は以下の解析式から得られます。

```
k* = (s / (δ + n + g + n·g))^(1/(1−α))
```

この定常状態での各変数：

- `y* = (k*)^α`
- `c* = (1−s) · y*`
- `inv* = s · y*`

## 資本蓄積方程式（離散時間）

```
k(t+1) = [s · k(t)^α + (1−δ) · k(t)] / [(1+n)(1+g)]
```

## 出力

`transition_path` / `simulate` は以下のフィールドを持つ NamedTuple を返します。

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `k`       | `Vector{Float64}` | 効率労働単位あたり資本の時系列 |
| `y`       | `Vector{Float64}` | 効率労働単位あたり生産の時系列 |
| `c`       | `Vector{Float64}` | 効率労働単位あたり消費の時系列 |
| `inv`     | `Vector{Float64}` | 効率労働単位あたり投資の時系列 |

## 基本的な使い方

```julia
using DME

# モデルのインスタンス化
m = SolowModel(
    0.3,   # α: 資本分配率
    0.2,   # s: 貯蓄率
    0.1,   # δ: 資本減耗率
    0.01,  # n: 人口成長率
    0.02,  # g: 技術進歩率
)

# 定常状態
ss = steady_state(m)
println("k* = ", ss.k)
println("y* = ", ss.y)
println("c* = ", ss.c)

# 移行経路（初期資本 = 定常状態の半分）
path = transition_path(m, ss.k / 2; T = 100)

# SimulationResult に変換
result = to_simulation_result(m, path, "transition_path")

# 描画
plot_result(result, ["k", "y", "c"])
```

## Ramsey/RBCモデルとの役割分担

| 項目 | Solow | Ramsey | RBC |
|------|-------|--------|-----|
| 家計の最適化 | なし（外生的貯蓄率） | あり | あり |
| 確率ショック | なし | なし | あり |
| 分析対象 | 定常状態・収束 | 最適蓄積経路 | 景気循環 |
| 解の計算 | 解析解・前向き反復 | NLsolve | 線形近似 |

## 限界

- 家計の効用最大化を扱わないため、厚生分析には適さない
- 貯蓄率 `s` は内生的に決定されない
- 確率的ショックは考慮しない
- 技術進歩は外生的に与えられ（全要素生産性の内生化なし）
