## 1. モデルの目的

> **LLM向け要約**: RBC モデルは「全要素生産性（TFP）の確率的変動が景気循環を引き起こす」という命題を検証するためのモデルである。代表的家計が消費・労働・貯蓄を最適化し、代表的企業が利潤を最大化する均衡において、技術ショックが産出・消費・投資・労働へどのように波及するかを定量的に分析する。

このモデルは、**実物ショック（技術ショック）が主要な景気変動要因**であるという Kydland-Prescott (1982) の仮説を実装した枠組みを提供する。

- **主な問い**: 生産性ショックが発生したとき、産出・消費・資本・労働・賃金・利子率はどのような動的調整過程をたどるか
- **対象経済**: 代表的家計・代表的企業からなる閉鎖経済（労働供給は弾力的）
- **時間軸**: 無限期間離散時間（完全予見経路は有限期間 T=150 で近似、IRF は線形化で計算）

---

## 2. 経済学的直観

### なぜこのモデルが重要か

RBC モデルは Ramsey モデルに **弾力的な労働供給** と **AR(1) 型の確率的技術ショック** を追加した拡張モデルである。名目硬直性や金融摩擦なしに、実物的なメカニズムだけで景気循環の主要な統計的特徴（産出・消費・投資の共変動など）を説明できるかを問う、現代マクロ経済学の出発点となった枠組みである。

### 直観的なメカニズム

- **正の技術ショック（TFP 上昇）**: 生産性が上がると企業は労働と資本の需要を増やす。賃金と利子率が上昇し、家計は労働供給を増やす（代替効果）とともに消費を増やす（所得効果）。産出・投資・消費がともに増加する「景気拡大」局面が生まれる
- **資本の動学**: 好景気に蓄積された資本は次期の生産基盤となる。資本の調整に時間がかかるため、ショックの効果は複数期間にわたって持続する（資本の内生的伝播メカニズム）
- **労働の内生性**: 家計が余暇と消費の最適なトレードオフを解くため、労働量が内生的に決まる。賃金が高い時期に多く働く「異時点間代替」がモデルの核心である
- **定常状態への収束**: 技術ショックが AR(1) 過程に従いゼロへ回帰するにつれ、すべての変数は定常値へ戻る。収束速度はショックの持続性 ρ と資本減耗率 δ によって決まる

## 3. 主要変数

### 状態変数

| 変数 | Julia シンボル | 意味 | 単位・スケール |
|---|---|---|---|
| 資本 | `:K` | 期初の資本ストック | レベル（実質） |
| 技術水準 | `:A` | 全要素生産性（TFP）。定常値は A* = 1 | レベル（無次元、定常値 = 1） |

### 操作変数（コントロール変数）

| 変数 | Julia シンボル | 意味 | 単位・スケール |
|---|---|---|---|
| 消費 | `:C` | 家計の消費量 | レベル（実質） |
| 労働 | `:L` | 家計の労働供給量 | レベル（時間単位） |

| 変数 | Julia シンボル | 意味 |

| 変数 | 意味 |
|---|---|
| 技術ショック `ϵ` | TFP の確率的変動。`log(A_{t+1}) = ρ * log(A_t) + ϵ_t`（AR(1) 過程） |

## 4. パラメータ

### Julia コンストラクタ

```julia
RBCModel(α, β, γ, δ, μ, ρ)
```

### パラメータ一覧

| パラメータ | Julia フィールド | 意味 | 標準的な値域 | 標準的なキャリブレーション値 |
|---|---|---|---|---|
| α | `α` | 資本分配率（コブ＝ダグラス生産関数の資本の指数） | (0, 1) | 0.3（米国データ実績） |
| β | `β` | 割引因子（1期の将来の効用を現在価値に換算する係数） | (0, 1) | 0.99（1期 = 1四半期の場合） |
| γ | `γ` | 労働供給の逆フリッシュ弾力性（余暇の効用の凸性を制御） | (0, ∞) | 1.0（フリッシュ弾力性 = 1 に対応） |
| δ | `δ` | 資本減耗率（1期間に消耗する資本の割合） | (0, 1) | 0.025（四半期）または 0.1（年次） |
| μ | `μ` | 労働不効用の大きさ（余暇選好の強さ） | (0, ∞) | 1.0（定常労働量を 1 前後にキャリブレーション） |
| ρ | `ρ` | 技術ショックの持続性（AR(1) の自己回帰係数） | [0, 1) | 0.9（高い持続性）または 0.95 |

### キャリブレーションの参照

- **α**: 国民経済計算の要素分配（労働分配率 = 1 − α）から推定。米国・日本とも概ね 0.3〜0.4
- **β**: 実質金利 r* から β ≈ 1/(1+r*) で逆算。年率 4% なら四半期 β ≈ 0.99
- **γ**: 労働経済学の実証研究によるフリッシュ弾力性（推定値は 0.5〜4 と幅広い）から設定
- **δ**: 固定資本消耗額 / 固定資本ストックから計算（SNA・BEA 統計）
- **μ**: 定常状態で望ましい労働量（例: L* ≈ 1/3）になるよう逆算して設定
- **ρ**: TFP データ系列（例: Solow 残差）をフィルタリングして AR(1) 係数を推定

## 5. 主要方程式

> **記法**: `t` は現在期、`t+1` は次期。`^` は対定常状態の対数偏差（IRF での表記）。

### 最適化問題

**家計の目的関数**:

```
max Σ_{t=0}^{∞} β^t [log(C_t) - μ * L_t^(γ+1)]

s.t. C_t + K_{t+1} = w_t * L_t + r_t * K_t + (1-δ) * K_t
     log(A_{t+1}) = ρ * log(A_t) + ϵ_t
```

### 均衡条件

| 方程式名 | 数式 | 経済学的意味 |
|---|---|---|
| 労働の最適条件（静学条件） | `w_t / C_t = (γ+1) * μ * L_t^γ` | 賃金の実質価値 = 余暇の限界不効用（労働と消費のトレードオフ） |
| オイラー方程式（動学条件） | `C_{t+1} / C_t = β * (r_{t+1} - δ + 1)` | 消費の平準化：現在と将来の限界効用の比が利子率に等しい |
| 生産関数 | `Y_t = A_t * K_t^α * L_t^(1-α)` | コブ＝ダグラス型 TFP 込み生産関数 |
| 賃金決定 | `w_t = (1-α) * A_t * K_t^α * L_t^(-α)` | 競争均衡での実質賃金 = 労働の限界生産物 |
| 資本蓄積 | `K_{t+1} = Y_t + (1-δ) * K_t - C_t` | 資本の法則（産出 + 残存資本 − 消費） |
| 利子率決定 | `r_t = α * A_t * K_t^(α-1) * L_t^(1-α)` | 競争均衡での実質利子率 = 資本の限界生産物 |
| 技術過程 | `log(A_{t+1}) = ρ * log(A_t)` | AR(1) 技術ショック（ϵ = 0 のとき定常状態へ収束） |

### 線形化された系（Blanchard-Kahn 法）

`solve_rbc` では定常状態周りの対数線形近似を用いる。状態ベクトルを `s_t = [k̂_t, â_t]`、制御ベクトルを `x_t = [ĉ_t, l̂_t, ŷ_t, ŵ_t, r̂_t]` として、

```
C_mat * [s_{t+1}; x_{t+1}] = B_mat * [s_t; x_t]
```

という 7 元連立線形方程式を解く。Blanchard-Kahn 条件（不安定固有値の数 = 先決変数の数 = 2）を満たすとき、遷移行列 `A_A`（2×2）と政策行列 `P`（5×2）が一意に決まる。

## 6. 定常状態

### 解析的な定常状態の導出

定常状態では `K_{t+1} = K_t = K*`, `A_t = A* = 1`, `C_{t+1} = C_t = C*` が成立する。

1. 技術水準を正規化: `A* = 1`
2. オイラー方程式に定常値を代入: `r* = 1/β + δ - 1`
3. 利子率決定式から K/L 比を求める: `K*/L* = (r* / (A* * α))^{1/(α-1)}`
4. 賃金決定式: `w* = (1-α) * A* * (K*/L*)^α`
5. 労働の最適条件と予算制約から L* を解く
6. `K* = (K*/L*) * L*`, `Y* = Y*/L* * L*`, `C* = C*/L* * L*`

### 定常状態の値

| 変数 | 解析式 | デフォルトパラメータ (α=0.3, β=0.99, γ=1.0, δ=0.025, μ=1.0, ρ=0.9) での参考値 |
|---|---|---|
| A* | `1` | 1.0（正規化） |
| r* | `1/β + δ - 1` | ≈ 0.035 |
| w* | `(1-α) * (K*/L*)^α` | パラメータに依存 |
| L* | `(w* / ((γ+1)*μ))^{1/(γ+1)} * C*^{-1/(γ+1)}` | パラメータに依存 |
| K* | `(K*/L*) * L*` | パラメータに依存 |
| Y* | `A* * K*^α * L*^{1-α}` | パラメータに依存 |
| C* | `Y* - δ * K*` | パラメータに依存 |

### Julia での計算

```julia
using DME

m = RBCModel(0.3, 0.99, 1.0, 0.025, 1.0, 0.9)
ep = steady_state(m)
# => (A = 1.0, r = 0.035..., w = ..., L = ..., K = ..., Y = ..., C = ...)

ep.K   # 定常資本
ep.C   # 定常消費
ep.L   # 定常労働
ep.r   # 定常利子率
ep.w   # 定常賃金
ep.Y   # 定常産出
ep.A   # 定常技術水準（常に 1.0）
```

低レベルの内部関数としても利用可能（非推奨）:

```julia
A_star, r_star, w_star, L_star, K_star, Y_star, C_star = DME.calc_ep(m)
```

## 7. ショック・シナリオ

### サポートされているシナリオ

| シナリオ | 推奨関数 | 内部実装関数 | 説明 |
|---|---|---|---|
| 完全予見経路 | `transition_path(m, A0, K0)` | `DME.find_path(m, A0, K0)` | 初期値 (A0, K0) から定常状態への移行経路（NLsolve） |
| インパルス応答関数 | `impulse_response(m, ε0)` | `DME.shock(m, ε0)` | t=0 の 1 期間技術ショック ε0 に対する IRF（線形化） |

### 標準的なシナリオ

| シナリオ | 設定例 | 経済学的意味 |
|---|---|---|
| 正の技術ショック（IRF） | `impulse_response(m, 0.01)` | TFP が 1% 上昇したときの各変数の動的調整を分析 |
| 負の技術ショック（IRF） | `impulse_response(m, -0.01)` | 景気後退局面での産出・消費・労働の落ち込みを分析 |
| 移行経路（完全予見） | `transition_path(m, 1.0, ep.K * 0.8)` | 資本不足（資本が定常値の 80%）から定常状態への移行 |

### ショックのサイズとスケール

- **IRF の `ε0`**: 対数スケールでの TFP ショック。`ε0 = 0.01` は「TFP が約 1% 上昇」に対応する
- IRF の出力変数（`â`, `k̂` など）は**対定常状態の対数偏差**。値を 100 倍すると % 偏差になる
- **`A0`**: レベルで指定。定常値は 1.0 なので `A0 = 1.1` は TFP が 10% 高い初期状態を意味する

## 8. 出力結果の読み方

### transition_path の返り値

```julia
using DME

m = RBCModel(0.3, 0.99, 1.0, 0.025, 1.0, 0.9)
ep = steady_state(m)

path = transition_path(m, 1.0, ep.K * 0.8)   # A0=1.0（定常値）、K0 = 定常値の 80%
path.K  # 資本系列   Vector{Float64}（長さ maxT+1）
path.C  # 消費系列
path.L  # 労働系列
path.Y  # 産出系列
path.r  # 利子率系列
path.w  # 賃金系列
path.A  # 技術水準系列
```

### impulse_response の返り値

```julia
irf = impulse_response(m, 0.01)   # ε0 = +1% の技術ショック

irf.â   # TFP の対数偏差系列    Vector{Float64}（長さ maxT+1）
irf.k̂   # 資本の対数偏差系列
irf.ĉ   # 消費の対数偏差系列
irf.l̂   # 労働の対数偏差系列
irf.ŷ   # 産出の対数偏差系列
irf.r̂   # 利子率の対数偏差系列
irf.ŵ   # 賃金の対数偏差系列
```

### IRF 変数の解釈

| 出力変数 | 単位 | 経済学的解釈 |
|---|---|---|
| `irf.â` | 対数偏差 | TFP の定常状態からの乖離。AR(1) に従い `t → ∞` でゼロへ収束する（持続性は ρ に依存） |
| `irf.k̂` | 対数偏差 | 資本の定常状態からの乖離。ショック直後はゼロ（先決変数）、その後の投資増により徐々に上昇し、遅れてピークを迎える |
| `irf.ĉ` | 対数偏差 | 消費の定常状態からの乖離。ショック直後から上昇し、資本より緩やかに収束する（消費平準化）  |
| `irf.l̂` | 対数偏差 | 労働の定常状態からの乖離。正のショックで上昇（異時点間代替）し、賃金効果とともに徐々にゼロへ収束 |
| `irf.ŷ` | 対数偏差 | 産出の定常状態からの乖離。TFP ショックに対してほぼ同期して反応し、最も大きな初期反応を示す |
| `irf.r̂` | 対数偏差 | 利子率の定常状態からの乖離。TFP 上昇で即座に上昇し、資本蓄積が進むにつれて下落する |
| `irf.ŵ` | 対数偏差 | 賃金の定常状態からの乖離。TFP と資本の増加を反映して持続的に上昇する |

### % 偏差への変換

```julia
# 対数偏差 × 100 ≈ % 偏差（小さなショックの場合）
percent_deviation_y = irf.ŷ * 100
```

### 典型的な IRF の特徴（正の技術ショック）

- **産出 `ŷ`**: ショック直後に大きく上昇、TFP の持続性（ρ）に応じて緩やかに収束
- **消費 `ĉ`**: ショック後に上昇するが産出より小さい反応（家計が一部を貯蓄に回す）
- **資本 `k̂`**: 0 期は変化なし（先決変数）、投資増により数期にわたって上昇してからピーク後に収束
- **労働 `l̂`**: ショック直後に上昇（代替効果が所得効果を上回る）、数期後に定常値へ
- **賃金 `ŵ`**: TFP 上昇に伴いすぐ上昇し、その後も資本の蓄積により比較的高い水準を維持
- **利子率 `r̂`**: ショック直後に上昇し、資本蓄積による限界生産物の逓減で徐々に下落

## 9. AIエコノミスト向け利用ガイド

### このモデルで答えられること（用途）

- 技術ショック（TFP 変動）が産出・消費・投資・労働・賃金・利子率に与える波及効果の定量分析
- 景気循環の「共変動事実（stylized facts）」の再現：産出・消費・投資の変動率の比較、労働との相関
- パラメータ変化（ρ, γ, δ など）が景気循環の振幅・持続性に与える影響の感度分析
- 定常状態における経済規模・要素分配（資本所得 / 労働所得）のキャリブレーション検証
- 初期資本ストックが定常値から乖離した場合の移行動態の分析

### このモデルでは答えられないこと（限界・非対象）

- **金融政策の効果**: 中央銀行の政策金利・量的緩和・フォワードガイダンスは扱わない（→ New Keynesian モデルが必要）
- **名目硬直性・インフレ動学**: 賃金・価格の硬直性、インフレ率、フィリップス曲線は存在しない（→ New Keynesian モデルが必要）
- **需要ショックの分析**: 政府支出ショック・需要不足・流動性トラップは扱わない
- **金融摩擦・信用サイクル**: 借入制約・担保制約・レバレッジサイクルは考慮しない
- **家計の異質性**: 所得・資産分布の不平等・信用制約のある家計の行動は分析できない
- **開放経済**: 貿易・経常収支・国際資本移動・為替レートは扱わない

### LLM が参照する際の注意点

- **変数スケール**: `transition_path` の出力はレベル、`impulse_response` の出力は対数偏差。単位を混同しないこと
- **IRF のインデックス**: `irf.â[1]` は t=0（ショック発生時点）、`irf.â[2]` は t=1 期後。ゼロインデックスではない
- **先決変数と飛躍変数**: `k̂` は先決変数（t=0 で必ずゼロ）、`ĉ` は飛躍変数（t=0 からジャンプ可能）
- **線形化の精度範囲**: `impulse_response` は定常状態近傍の線形近似。ショックサイズが大きい（例: ε0 > 0.1）と精度が低下する
- **ρ = 1 の回避**: 技術ショックの持続性 ρ が 1 に等しい場合（単位根）、Blanchard-Kahn 条件が成立しない可能性がある。ρ は必ず 1 未満に設定すること
- **`transition_path` の初期値**: A0 = 1.0（定常値）固定で K0 のみ変えるのが標準的な使い方

## 10. モデルの限界

### 理論的限界

| 限界 | 説明 |
|---|---|
| 名目変数の欠如 | 物価・名目賃金・名目金利・インフレ率が存在しない純粋な実物モデルである |
| 代表的家計仮定 | 家計間の異質性（所得格差・資産不平等・信用制約）を捨象している |
| 完全競争・完全市場 | 独占的競争・市場の失敗・外部性を考慮しない |
| 技術ショックのみ | 需要ショック・政府支出ショック・金融ショックを扱わない |
| 閉鎖経済 | 国際貿易・経常収支・国際資本移動を考慮しない |
| 確率的ショックの線形近似 | `impulse_response` は定常状態近傍での一次近似。大きなショックや非線形効果を過小評価する |

### 数値的限界

| 限界 | 説明 | 回避策 |
|---|---|---|
| 線形近似誤差 | Blanchard-Kahn 法は定常状態近傍でのみ精度が高い | 小さいショックサイズ（ε0 ≤ 0.05 程度）を使用する |
| ρ → 1 の不安定性 | 技術ショックの持続性が 1 に近いと固有値分解が不安定になる | ρ は必ず 1 未満（例: ρ ≤ 0.99）に設定する |
| `find_path` の有限期間近似 | T=150 期で終端を定常値に固定するため、ρ が高い場合に終端誤差が生じる | maxT を十分大きく設定する（例: `maxT=300`） |
| NLsolve の収束 | `transition_path` は T×7 本の非線形連立方程式を解くため、初期値が定常値から大きく離れると収束しない場合がある | 初期値を定常値に近い値から始める |

## 11. 実データとの対応づけ

### 候補系列

| モデル変数 | 実データ系列（日本） | 実データ系列（米国） | 備考 |
|---|---|---|---|
| K（資本） | 国民経済計算（SNA）: 固定資本ストック | BEA: Fixed Assets | 名目値を GDP デフレーターで実質化 |
| C（消費） | SNA: 家計最終消費支出 | BEA NIPA: PCE | 耐久財を除くケースもある |
| Y（産出） | SNA: 実質 GDP | BEA NIPA: Real GDP | 季節調整済み系列を使用 |
| L（労働） | 労働力調査: 総実労働時間 | BLS: Total Hours Worked | 就業者数 × 平均労働時間 |
| r（利子率） | 日本銀行: コールレート / 長期金利 | FRED: Federal Funds Rate / 10yr Treasury | 名目金利からインフレ率を差し引いて実質化 |
| w（賃金） | 毎月勤労統計: 実質賃金指数 | BLS: Real Compensation per Hour | 名目賃金 / GDP デフレーター |
| A（TFP） | JIP データベース: TFP 成長率 | FRED: TFP（Fernald 2012） | HP フィルタで循環成分を抽出後、AR(1) 係数を推定 |

### キャリブレーション手順の概要

1. 長期平均から α（資本分配率）を推定（国民所得統計の資本報酬 / 要素所得）
2. 実質金利の長期平均から β を逆算（β ≈ 1/(1+r*)）
3. 国民経済計算の固定資本消耗 / 固定資本ストックから δ を設定
4. TFP データ系列を HP フィルタで循環成分に分解し、AR(1) 回帰から ρ を推定
5. 定常労働量 L* の目標値（例: 就業可能時間の 1/3）から μ を逆算

## 付録: DME での実装詳細

### 求解アルゴリズムの概要

1. `steady_state(m)` → 均衡条件を解析的に代入して (A*, r*, w*, L*, K*, Y*, C*) を計算（`DME.calc_ep`）
2. `transition_path(m, A0, K0)` → NLsolve で T=150 期分の 7T 本の連立方程式を一括求解（`DME.find_path`）
3. `impulse_response(m, ε0)` → `DME.solve_rbc` で線形化行列 (A_A, P) を取得し、`DME.shock` でインパルス応答を計算

### `solve_rbc` の線形化行列

高度な用途では `DME.solve_rbc` を直接呼び出して遷移行列を取得できる:

```julia
using DME

m = RBCModel(0.3, 0.99, 1.0, 0.025, 1.0, 0.9)

# 線形化行列を取得
A_A, P = DME.solve_rbc(m)
# A_A: 2×2 状態遷移行列（k̂, â の動学）
# P: 5×2 政策行列（ĉ, l̂, ŷ, ŵ, r̂ を状態変数の関数として表現）

# 状態変数の動学: s_{t+1} = A_A * s_t
# 制御変数:       x_t     = P * s_t
# （s_t = [k̂_t, â_t]）
```

### `shock` 関数の内部動作

```julia
# impulse_response(m, ε0) の内部
A_A, P = solve_rbc(m)
S = zeros(maxT+1, 2)
S[1, :] = [0, ε0]        # t=0: k̂=0（先決変数）, â=ε0（ショック）
for i in 1:maxT
    S[i+1, :] = A_A * S[i, :]  # 状態遷移
end
X = (P * S')'             # 制御変数の時系列
# X の列: [ĉ, l̂, ŷ, ŵ, r̂]
```

### 既知の数値的注意点

- `solve_rbc` はモデルパラメータが Blanchard-Kahn 条件（安定固有値が 2 個、不安定固有値が 5 個）を満たす前提で動作する。条件を満たさない場合、固有値分解後の逆行列計算でエラーが生じる
- ρ が 1 に近い（例: 0.99）と技術ショックの減衰が非常に遅くなり、`impulse_response` の収束が視覚的に確認しにくくなる。`maxT` を大きくして（例: `maxT=300`）全体の収束を確認すること
- `transition_path` の初期値として A0 = 1.0（定常値）+ 定常値近傍の K0 を設定するのが収束しやすい
