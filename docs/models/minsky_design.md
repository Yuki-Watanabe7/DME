# Minsky系金融不安定性モデル 設計方針

> 関連Issue: #99（ロードマップ）・#100（候補調査・比較）

---

## 1. 背景と目的

DME は現在、実物側の動学モデル（Ramsey・Solow・RBC）と短期需要側モデル（IS-LM・AD-AS・New Keynesian・Mundell-Fleming）を実装しているが、
**金融循環・信用循環を内生化したモデル**を持たない。
Minsky の金融不安定性仮説（Financial Instability Hypothesis, FIH）に基づくモデルを追加することで、

- 好況期の信用拡大が債務比率を高め、内生的に不安定化するメカニズムの分析
- Hedge / Speculative / Ponzi という資金繰り区分に基づく金融脆弱性の説明
- 既存 DSGE/RBC 系モデル（外生ショック駆動）との対比

が可能になる。

本ドキュメントは、DME 初版で採用する Minsky 系数理モデルを選定するための調査・比較メモである。
実装そのもの・DME アーキテクチャへの統合設計（#101）・実データ接続は対象外とする。

## 2. 候補モデルの概要

### 2.1 Keen モデル（Goodwin-Keen モデル）

Keen (1995) が Goodwin (1967) の成長循環モデルに**企業債務**を導入して
Minsky の FIH を定式化したモデル。数学的な性質は Grasselli & Costa Lima (2012) が厳密に解析している。

状態変数は 3 つ（すべて比率で定義される連続時間 ODE 系）:

| 変数 | 記号 | 定義 |
|---|---|---|
| 賃金シェア | `ω` | `wL / Y` |
| 雇用率 | `λ` | `L / N` |
| 民間債務比率 | `d` | `D / Y` |

**構造方程式**（Grasselli & Costa Lima 2012 の定式化）:

```
π  = 1 - ω - r d                        （利子支払後の利潤シェア）
ω' = ω [Φ(λ) - α]                       （実質賃金の Phillips 曲線動学）
λ' = λ [κ(π)/ν - δ - α - β]             （資本蓄積による雇用率動学）
d' = κ(π) - π - d [κ(π)/ν - δ]          （投資と内部資金の差 = 新規借入）
```

代表的な関数形:

```
Φ(λ) = φ1 / (1 - λ)^2 - φ0              （非線形 Phillips 曲線）
κ(π) = κ0 + κ1 exp(κ2 π)                （利潤感応的な投資関数）
```

パラメータは `α`（労働生産性成長率）・`β`（労働人口成長率）・`δ`（資本減耗率）・
`ν`（資本産出比率）・`r`（貸出金利）と関数形パラメータ 5 個の**計 10 個程度**。

**動学的特徴**（Grasselli & Costa Lima 2012）:

- **良い均衡**: 有限の `(ω̄, λ̄, d̄)` で成長率 `α + β` に収束。均衡値は閉形式で計算できる
  （`κ(π̄) = ν(α + β + δ)` から `π̄`、`λ̄ = Φ⁻¹(α)`、`d̄ = (κ(π̄) - π̄)/(α + β)`）。
- **悪い均衡**: `(ω, λ) → (0, 0)`・`d → ∞` の債務崩壊（債務デフレ）も局所安定な吸引域を持つ。
- 初期条件により良い均衡と債務崩壊のどちらに向かうかが分かれる**双安定性**が、
  金融脆弱性（fragility）の自然な定量表現になる。

### 2.2 Ryoo モデル

Ryoo (2010) は Kaleckian な財市場の短期循環（Harrod 的不安定性）と、
企業・家計・銀行の金融ストックが駆動する **Minsky 的長期波動**を組み合わせたモデル。

- 状態変数: 企業の負債資本比率・家計のポートフォリオ構成（株式保有比率）・
  株価（Tobin の `q`）・期待成長率など **6〜7 変数**の連続時間 ODE 系（fast-slow 構造）
- 短期循環と長期波動という 2 つの時間スケールを同時に扱える点が特長
- パラメータは 20 個前後。均衡・安定性の解析は数値依存の部分が多く、
  Keen モデルにおける Grasselli & Costa Lima のような標準的な数値検証のアンカーが薄い
- 資産価格・ポートフォリオ選択を明示するため、Minsky の「投機的な資産価格上昇」の側面を
  Keen モデルよりも忠実に表現できる

### 2.3 Godley-Lavoie（Stock-Flow Consistent, SFC）モデル

Godley & Lavoie (2007) *Monetary Economics* の SFC モデル群。
バランスシート行列・取引フロー行列で部門間（家計・企業・銀行・政府・中央銀行）の
ストックとフローの整合性を会計的に保証する**離散時間の連立方程式体系**。

- 最小の教科書モデル SIM で 10 本強、銀行・成長を含む GROWTH モデルでは **100 本超**の方程式
- 各期ごとに非線形連立方程式を解く（Gauss-Seidel 反復や Newton 法。`NLsolve` で対応可能）
- Minsky 的な景気循環そのものは自動的には生まれず、行動方程式の設計に依存する
- モデルというより**フレームワーク**であり、Keen モデルや Ryoo モデルは
  SFC の観点から見ると特定の会計構造を低次元に縮約したものと位置づけられる
  （Ryoo モデルは SFC 整合的に構築されている。Keen (1995) 原型は会計整合性に批判があったが、
  Grasselli & Costa Lima (2012) の定式化では整合的な会計解釈が与えられている）

DME のロードマップ（#99）でも SFC は将来的な発展として位置づけられており、
本選定では「初版モデルの候補」というより「拡張の到達点」として整理する。

## 3. 候補モデルの比較表

| 項目 | Keen | Ryoo | Godley-Lavoie (SFC) |
|---|---|---|---|
| **時間概念** | 連続（ODE） | 連続（ODE） | 離散（差分・連立方程式） |
| **状態変数数** | 3（`ω, λ, d`） | 6〜7 | 数十〜100 超（モデル規模による） |
| **方程式数** | ODE 3 本 + 定義式 | ODE 6〜7 本 + 定義式 | 10 本強（SIM）〜100 本超（GROWTH） |
| **パラメータ数（目安）** | 約 10 | 約 20 | 数十 |
| **計算量・解法** | 低（固定刻み RK4 で十分） | 中（fast-slow で刻み幅に注意） | 中〜高（毎期の非線形連立方程式求解） |
| **債務主導の内生循環** | ○ | ○ | 行動方程式の設計次第 |
| **債務崩壊（債務デフレ）の再現** | ○（悪い均衡への収束） | ○ | 設計次第 |
| **資産価格・ポートフォリオ** | なし | ○（Tobin の q・株式） | ○ |
| **部門間会計整合性** | 縮約形（明示せず） | SFC 整合 | ○（フレームワークの核） |
| **均衡の閉形式・解析結果** | ○（Grasselli & Costa Lima 2012） | 数値依存 | なし（数値のみ） |
| **数値検証テストの書きやすさ** | ○（均衡値・安定性条件が文献にある） | △ | △（会計恒等式の検証は可能） |
| **Hedge/Speculative/Ponzi 判定との接続** | ○（`π`・`rd`・`κ(π)` から直接定義可能） | ○ | ○ |
| **既存 DME との親和性** | 高（Solow/RBC 同様の低次元動学） | 中 | 低（会計行列基盤の新設が必要） |
| **実装複雑度** | 低 | 中〜高 | 高 |
| **標準文献** | Keen (1995), Grasselli & Costa Lima (2012) | Ryoo (2010, 2013) | Godley & Lavoie (2007) |

## 4. 扱いたい問いの整理

| 問い | 対応する分析 |
|---|---|
| 好況期の信用拡大はなぜ不安定化を招くか | 利潤 → 投資 → 借入 → 債務比率上昇 → 利払い負担 → 利潤圧迫のフィードバック |
| 債務崩壊（債務デフレ）は内生的に起きるか | 悪い均衡（`d → ∞`）への収束経路の提示 |
| どの初期条件・パラメータで経済は脆弱になるか | 良い均衡の吸引域の広さ・金利 `r` や投資感応度の比較静学 |
| 企業の資金繰りはどの区分にあるか | Hedge / Speculative / Ponzi の時系列判定（後続の分析機能） |
| 外生ショック駆動モデルとの違いは何か | RBC/NK との比較（ショックなしで循環・崩壊が生じる点） |

これらの問いはすべて **Keen モデル**の枠組みで直接分析できる。
資産価格バブルを明示的に扱う問いは Ryoo 型拡張、部門間資金フローを扱う問いは SFC への拡張が必要となる。

## 5. 採用モデルの選定

### 選定: **Keen モデル（Goodwin-Keen 3 変数 ODE 系、Grasselli & Costa Lima 2012 定式化）**

#### 選定理由

1. **実装複雑度が最も低い**: 状態変数 3・パラメータ約 10 の ODE 系であり、
   固定刻みの RK4 を自前実装すれば**新規依存パッケージなし**で完結する。
   均衡値は閉形式で求まるため `NLsolve` すら必須ではない。

2. **Minsky の中核メカニズムを最小構成で再現**: 「安定が不安定を生む」という FIH の核心
   （利潤改善 → 投資拡大 → 債務蓄積 → 崩壊リスク）と、良い均衡・債務崩壊の双安定性を
   3 変数で表現できる。

3. **数値検証テストのアンカーがある**: Grasselli & Costa Lima (2012) に均衡値の閉形式・
   局所安定性条件・数値例があり、DME の他モデルと同様の数値検証テストを文献値に対して書ける。

4. **分析機能への接続が自然**: Hedge / Speculative / Ponzi 判定は
   `π`（内部資金）・`r d`（利払い負担）・`κ(π)`（投資）の大小関係から直接定義でき、
   金融不安定性指標（債務比率・利払い/利潤比など）も状態変数から即座に計算できる。

5. **既存 DME との親和性**: 低次元動学モデルとして Solow / RBC と同じ
   `AbstractMacroModel` インターフェース（`steady_state` / `simulate` など）に自然に適合する
   （統合設計の詳細は #101）。

6. **拡張路線が明確**: Keen →（資産価格・ポートフォリオを加えた）Ryoo 型拡張 →
   Godley-Lavoie SFC という段階的な発展パスが描ける。

#### 見送りとした候補

| モデル | 見送り理由 |
|---|---|
| Ryoo | 状態変数・パラメータが多く初版のスコープを超える。数値検証のアンカーとなる標準的解析が薄い。資産価格を扱う後続拡張の第一候補とする |
| Godley-Lavoie (SFC) | 会計行列基盤（バランスシート・取引フロー行列）の新設が必要で方程式数も桁違い。将来的な発展として検討し、Keen モデル実装をその足掛かりとする |

選定の正式な決定記録は [ADR 0001](../adr/0001-minsky-model-selection.md) を参照。

## 6. 最小実装のスコープ

### 6.1 モデル構造

§2.1 の Grasselli & Costa Lima (2012) 定式化をそのまま採用する。

- 状態変数: `ω`（賃金シェア）・`λ`（雇用率）・`d`（民間債務比率）
- 派生変数: `π = 1 - ω - r d`（利潤シェア）・`g = κ(π)/ν - δ`（実質成長率）
- 関数形: `Φ(λ) = φ1/(1-λ)^2 - φ0`、`κ(π) = κ0 + κ1 exp(κ2 π)`
- パラメータ: `α, β, δ, ν, r, φ0, φ1, κ0, κ1, κ2`
- 数値解法: 固定刻み RK4（自前実装、新規依存なし）。刻み幅はパラメータで調整可能とする

デフォルトパラメータは Grasselli & Costa Lima (2012) の数値例
（`ν = 3, α = 0.025, β = 0.02, δ = 0.01, r = 0.03` ほか）をベースにする。

### 6.2 提供する機能

| 機能 | 内容 |
|---|---|
| `steady_state` | 良い均衡 `(ω̄, λ̄, d̄, π̄)` を閉形式で返す |
| `simulate` | 初期値 `(ω0, λ0, d0)` からの時間発展（`SimulationResult` 形式） |
| 収束判定 | 良い均衡へ収束したか・債務崩壊経路かの判定フラグ |

### 6.3 対象外（最小実装では扱わない）

- Hedge / Speculative / Ponzi 判定・金融不安定性指標（後続の分析機能 Issue へ）
- 政府部門・カウンターシクリカル財政の追加（Costa Lima et al. 型拡張）
- 資産価格・ポートフォリオ選択（Ryoo 型拡張へ）
- SFC 会計行列基盤
- 実データ接続・キャリブレーション
