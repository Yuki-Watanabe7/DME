## 1. モデルの目的

> **LLM向け要約**: Ramsey モデルは「代表的家計が無限期間にわたって生涯消費の割引現在価値を最大化するとき、最適な資本蓄積経路と消費経路はどうなるか」を分析する、現代マクロ経済学の基礎的なモデルである。

このモデルは、資本蓄積・消費平準化・最適成長経路を内生的に決定する枠組みを提供する。

- **主な問い**: 家計が資本蓄積を通じて生涯消費を最大化するとき、最適な資本・消費経路はどうなるか
- **対象経済**: 代表的家計・代表的企業からなる閉鎖経済（労働供給は非弾力的）
- **時間軸**: 無限期間離散時間（求解は有限期間 T=30 で近似）

---

## 2. 経済学的直観

### なぜこのモデルが重要か

Ramsey モデルは消費平滑化と貯蓄の動機を内生化する最も基本的な枠組みであり、現代マクロ経済学のほぼすべての動的モデル（RBC・DSGE・OLG など）の出発点となっている。外生的な貯蓄率を仮定するソローモデルと異なり、家計の最適化行動から貯蓄率が内生的に決まる点が最大の特徴である。

### 直観的なメカニズム

- 資本が少ないほど資本の限界生産物が高くなり、投資のリターンが大きくなる
- 家計は現在消費と将来消費のトレードオフを割引因子 β に基づいて最適化する（消費平準化）
- 資本が定常状態を下回る場合、高い収益率に誘われて投資を増やし資本を蓄積する
- 定常状態では資本の限界生産物と割引率が一致する（修正黄金律: `α K*^{α-1} = 1/β - (1-δ)`）
- 初期資本が定常値より低ければ、消費・資本ともに単調に定常状態へ収束する

## 4. パラメータ

### Julia コンストラクタ

```julia
RamseyModel(α, β, δ)
```

### パラメータ一覧

| パラメータ | Julia フィールド | 意味 | 標準的な値域 | 標準的なキャリブレーション値 |
|---|---|---|---|---|
| α | `α` | 資本分配率（コブ＝ダグラス生産関数の資本の指数） | (0, 1) | 0.3（米国データ実績） |
| β | `β` | 割引因子（1期の将来の効用を現在価値に換算する係数） | (0, 1) | 0.99（1期 = 1四半期の場合） |
| δ | `δ` | 資本減耗率（1期間に消耗する資本の割合） | (0, 1) | 0.025（四半期ベース）または 0.1（年次ベース） |

### キャリブレーションの参照

- α: 国民経済計算の要素分配（労働分配率 = 1 − α）から推定。米国・日本とも概ね 0.3〜0.4
- β: 実質金利 r* から β ≈ 1/(1+r*) で逆算。年率 4% なら四半期 β ≈ 0.99
- δ: 固定資本消耗額 / 固定資本ストックから計算（SNA・BEA 統計）

## 5. 主要方程式

> **記法**: `t` は現在期、`t+1` は次期。

### 最適化問題

**目的関数**:

```
max Σ_{t=0}^{∞} β^t log(C_t)

s.t. K_{t+1} = K_t^α + (1-δ)K_t - C_t   （資本蓄積方程式）
     C_t > 0, K_t > 0
```

### 均衡条件

| 方程式名 | 数式 | 経済学的意味 |
|---|---|---|
| オイラー方程式 | `C_{t+1}/C_t = β [α K_{t+1}^{α-1} - δ + 1]` | 消費の動学的最適化条件（消費平準化） |
| 資本蓄積 | `K_{t+1} = K_t^α + (1-δ)K_t - C_t` | 資本の法則（生産 + 残存資本 − 消費） |
| 生産関数 | `Y_t = K_t^α` | コブ＝ダグラス型（労働 = 1 に正規化） |
| 効用関数 | `U(C) = log(C)` | 対数効用（相対的危険回避度 = 1） |

## 6. 定常状態

### 解析的な定常状態の導出

定常状態では `K_{t+1} = K_t = K*`, `C_{t+1} = C_t = C*` が成立する。

1. オイラー方程式に定常値を代入: `1 = β [α K*^{α-1} - δ + 1]`
2. K* を解く: `K* = (α / (1/β + δ - 1))^{1/(1-α)}`
3. 資本蓄積式に代入: `C* = K*^α - δ K*`

### 定常状態の値

| 変数 | 解析式 | デフォルトパラメータ (α=0.3, β=0.99, δ=0.25) での値 |
|---|---|---|
| K* | `(α / (1/β + δ - 1))^{1/(1-α)}` | ≈ 1.226 |
| C* | `K*^α - δ K*` | ≈ 0.757 |

### Julia での計算

```julia
using DME

m = RamseyModel(0.3, 0.99, 0.25)
ep = steady_state(m)
# => (K = 1.226..., C = 0.757...)

ep.K  # 定常資本
ep.C  # 定常消費
```

低レベルの内部関数としても利用可能（非推奨）:

```julia
K_star, C_star = DME.calc_ep(m)
```

## 7. ショック・シナリオ

### サポートされているシナリオ

| シナリオ | 推奨関数 | 内部実装関数 | 説明 |
|---|---|---|---|
| 完全予見経路 | `transition_path(m, K0)` | `DME.find_path(m, K0)` | 初期資本 K0 から定常状態への移行経路（NLsolve） |
| 価値反復法シミュレーション | `simulate(m, K0)` | `DME.simulate_by_nlvar(m, K0)` | ポリシー関数に基づく動態シミュレーション |

### 標準的なシナリオ

| シナリオ | 初期値の例 | 経済学的意味 |
|---|---|---|
| 資本不足からの回復 | `K0 = ep.K / 2` | 戦後復興・発展途上国の急成長局面を模倣 |
| 資本過剰からの調整 | `K0 = ep.K * 1.5` | 過剰投資後の調整（消費が先行して増加）を分析 |

### ショックのサイズとスケール

`K0` はレベルで指定する。定常値 `ep.K` からの偏差率を制御したい場合は `K0 = ep.K * (1 + Δ)` のように設定する（例: 50% 低い場合は `K0 = ep.K * 0.5`）。

## 8. 出力結果の読み方

### 返り値の構造

```julia
# transition_path / simulate の返り値 (NamedTuple)
result = transition_path(m, ep.K / 2)
result.K  # 資本系列  Vector{Float64}（長さ T+1）
result.C  # 消費系列  Vector{Float64}（長さ T+1）

# SimulationResult への変換（汎用的な後処理に便利）
sr = to_simulation_result(m, result, "transition")
sr["K"]       # 資本系列の取得
sr["C"]       # 消費系列の取得
nperiods(sr)  # 期間数
```

### 変数系列の解釈

| 出力変数 | インデックス | 単位 | 解釈 |
|---|---|---|---|
| `result.K` | `K[1]` = K0（初期値）, `K[t]` = t 期初の資本ストック | レベル | 定常値 K* と比較して乖離を確認する |
| `result.C` | `C[t]` = t 期の消費 | レベル | 定常値 C* と比較して消費の調整速度を確認する |

### `find_path` と `simulate_by_nlvar`（`transition_path` と `simulate`）の違い

| 比較軸 | `transition_path` (`find_path`) | `simulate` (`simulate_by_nlvar`) |
|---|---|---|
| 求解方法 | NLsolve で T 期間分の連立方程式を一括解法 | 価値反復法でポリシー関数を求めてからシミュレーション |
| 終端条件 | T+1 期の消費・資本を定常値に固定（完全予見） | なし（ポリシー関数が暗黙的に無限期間の最適化を反映） |
| 用途 | 初期値から定常状態への最適移行経路を厳密に求めたい場合 | ポリシー関数自体を解析したい・任意初期値から繰り返しシミュレーションしたい場合 |
| 計算コスト | 低〜中（NLsolve の収束速度に依存） | 高（価値反復法の反復計算が必要） |
| 精度 | 終端条件の T 依存性あり（T が大きいほど精度向上） | グリッド数 `n` と補間方式に依存 |

### 典型的な結果の特徴

- **K0 < K*（資本不足）**: 資本は単調に K* へ増加。消費は当初抑制され、資本蓄積が進むにつれて緩やかに上昇する。
- **K0 > K*（資本過剰）**: 資本は単調に K* へ減少。消費は当初高く、徐々に C* へ収束する。
- **収束速度**: β が 1 に近いほど・δ が小さいほど収束が遅くなる傾向がある。

## 9. AIエコノミスト向け利用ガイド

### このモデルで答えられること（用途）

- 資本課税・補助金変更が定常状態の資本・消費・厚生に与える影響分析
- 初期資本ストックの水準が異なる国々の成長経路の比較（収束仮説の検証）
- 割引因子・資本減耗率の変化が長期的な資本蓄積に与える影響
- 完全予見下での最適消費・投資の動的調整過程のシミュレーション
- ポリシー関数（消費関数）の形状分析：資本水準に対する最適消費の感応度

### このモデルでは答えられないこと（限界・非対象）

- **景気循環の分析**: 確率的ショックがないため景気変動（ビジネスサイクル）の説明には使えない（→ RBC モデルを使用）
- **金融政策・名目硬直性**: 物価水準・インフレーション・金利政策チャンネルは扱わない（→ New Keynesian モデルが必要）
- **不確実性の効果**: 予防的貯蓄動機・リスクプレミアムを捉えられない
- **家計の異質性**: 所得・資産分布の不平等・貧困分析はできない（代表的家計を仮定）
- **労働市場の摩擦**: 失業・賃金硬直性・労働供給の弾力性は考慮されない
- **開放経済・国際資本移動**: 閉鎖経済の仮定のため、貿易・経常収支は扱わない

### LLM が参照する際の注意点

- **パラメータ感度**: β が 1 に非常に近い場合（例: 0.999）、定常資本ストックが大きくなり数値解が不安定になる
- **スケール**: 変数はレベルで返される。% 偏差への変換は `(result.K / ep.K - 1) * 100` のように手動で行う
- **デフォルト期間数**: T=30 は四半期換算で 7.5 年。長期の移行動態を分析する場合は `maxT` を大きく設定する
- **グリッド範囲外**: `simulate` の初期値 K0 が `ValueIterationOptions` のグリッド範囲 `[a, b]`（デフォルト: [0.5, 3.0]）外だと外挿誤差が生じる
- **労働の正規化**: 労働供給 L = 1 に固定されているため、産出は Y = K^α で計算される

## 10. モデルの限界

### 理論的限界

| 限界 | 説明 |
|---|---|
| 代表的家計仮定 | 家計間の異質性（所得格差・資産不平等・信用制約）を捨象している |
| 確実性等価 | 確率的ショックがなく、不確実性下の最適化（リスク回避・予防的貯蓄）を扱わない |
| 労働市場の単純化 | 労働供給を 1 に固定しており、雇用変動・賃金決定を内生化していない |
| 金融市場なし | 借入・貸出・資産価格・金融政策チャンネルが存在しない |
| 閉鎖経済 | 国際貿易・資本移動・為替レートを考慮しない |

### 数値的限界

| 限界 | 説明 | 回避策 |
|---|---|---|
| グリッドサイズ（価値反復法） | 精度はグリッド数 `n` に依存し、デフォルト n=20 は粗い近似 | `ValueIterationOptions(n=50)` 以上で精度向上 |
| グリッド範囲外の外挿 | K0 が `[a, b]` 外のとき補間精度が低下する | `ValueIterationOptions(a=..., b=...)` でグリッド範囲を調整 |
| 有限期間近似 | `find_path` は T=30 の有限期間問題として解くため、終端条件に依存する | `maxT` を大きく設定することで近似精度が向上する |
| β → 1 の収束問題 | 割引因子が 1 に近いとき価値反復法の収束が遅くなる | `max_iter` を増やすか `tolerance` を緩める |

## 11. 実データとの対応づけ

### 候補系列

| モデル変数 | 実データ系列（日本） | 実データ系列（米国） | 備考 |
|---|---|---|---|
| K（資本） | 国民経済計算（SNA）: 固定資本ストック | BEA: Fixed Assets | 名目値を GDP デフレーターで実質化 |
| C（消費） | SNA: 家計最終消費支出 | BEA NIPA: PCE | 耐久財を含む場合と除く場合がある |
| Y（産出） | SNA: 実質 GDP | BEA NIPA: Real GDP | 季節調整済み系列を使用 |

### キャリブレーション手順の概要

1. 長期平均から α（資本分配率）を推定（国民所得統計の資本報酬 / 要素所得）
2. 実質金利の長期平均から β を逆算（β ≈ 1/(1+r*)）
3. 国民経済計算の固定資本消耗 / 固定資本ストックから δ を設定

## 付録: DME での実装詳細

### 求解アルゴリズムの概要

1. `steady_state(m)` → オイラー方程式を代入して K*, C* を解析的に計算（`DME.calc_ep`）
2. `transition_path(m, K0)` → NLsolve で T=30 期分の連立方程式（2T 本）を一括求解（`DME.find_path`）
3. `simulate(m, K0)` → `solve_by_nlvar` で価値反復法によりポリシー関数 hc(K) を求め、K_{t+1} = g(K_t, hc(K_t)) を逐次計算（`DME.simulate_by_nlvar`）

### `solve_by_nlvar` のポリシー関数取得

高度な用途（ポリシー関数の直接利用）では `DME.solve_by_nlvar` を使用できる:

```julia
using DME

m = RamseyModel(0.3, 0.99, 0.25)

# ポリシー関数 hc: K -> C を取得
hc = DME.solve_by_nlvar(m)
hc(1.0)  # K=1.0 での最適消費
hc(1.5)  # K=1.5 での最適消費
```

### 数値計算オプション

```julia
# ValueIterationOptions（価値反復法のパラメータ調整）
opts = ValueIterationOptions(
    n         = 20,      # グリッドサイズ（大きいほど精度↑・計算時間↑）
    a         = 0.5,     # 資本グリッドの下限
    b         = 3.0,     # 資本グリッドの上限
    max_iter  = 100,     # 最大反復回数
    tolerance = 0.0001,  # 収束判定基準
    itp_type  = ITPCubic # 補間方式（ITPCubic / ITPLinear / ITPCheb）
)

result = simulate(m, ep.K / 2; vi_opts = opts)
```

### 既知の数値的注意点

- K0 を `[a, b]` の外に設定すると外挿が発生し精度が低下する。K0 が大きく外れる場合はグリッド範囲を広げること
- β が 1 に非常に近い場合（例: 0.999）、収束が遅くなる。`max_iter` を増やすか `tolerance` を緩めることで対処できる
- `find_path` の終端条件として T+1 期の値を定常値に固定しているため、T が小さいと終端からの誤差が経路全体に影響する。長期の分析には `maxT = 100` 以上を推奨する
