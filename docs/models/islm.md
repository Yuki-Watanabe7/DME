# IS-LMモデル

## 目的

IS-LMモデルは、財市場（IS曲線）と貨幣市場（LM曲線）の同時均衡を分析するための静学マクロ経済モデルです。
産出 `Y`（所得）と名目利子率 `r` を内生的に決定し、財政政策（政府支出・税）や金融政策（マネーサプライ）が
経済に与える短期的な影響を分析します。

RBC・Ramseyモデルとは異なり、価格（物価水準 `P`）は固定されており、家計・企業の動学的最適化は扱いません。
AD-ASモデルやNew Keynesianモデルへ進む橋渡しとして位置づけられます。

## 変数

| 変数 | 説明 |
|------|------|
| `Y`  | 実質GDP（産出・所得） |
| `r`  | 名目利子率 |
| `C`  | 消費 |
| `I`  | 投資 |

## パラメータ・外生変数

### 消費関数

| パラメータ | 説明 | 典型値 |
|-----------|------|--------|
| `c0`      | 自律消費 | 100.0 |
| `c1`      | 限界消費性向 MPC (0 < c1 < 1) | 0.8 |

### 投資関数

| パラメータ | 説明 | 典型値 |
|-----------|------|--------|
| `I0`      | 自律投資 | 200.0 |
| `b`       | 投資の利子率感応度 (b > 0) | 50.0 |

### 財政・外生変数

| 変数 | 説明 | 典型値 |
|------|------|--------|
| `G`  | 政府支出 | 100.0 |
| `T`  | 税（定額税） | 100.0 |

### 貨幣市場

| パラメータ/変数 | 説明 | 典型値 |
|----------------|------|--------|
| `l1`           | 貨幣需要の所得感応度 (l1 > 0) | 0.2 |
| `l2`           | 貨幣需要の利子率感応度 (l2 > 0) | 100.0 |
| `M`            | 名目マネーサプライ | 1000.0 |
| `P`            | 物価水準（固定） | 1.0 |

## IS曲線とLM曲線

### IS曲線（財市場の均衡）

支出恒等式: `Y = C + I + G`

消費関数と投資関数を代入:

```
Y = c0 + c1*(Y - T) + I0 - b*r + G
Y*(1 - c1) = A - b*r    （A = c0 - c1*T + I0 + G）
```

IS曲線（Y と r の関係）:
```
r = [A - (1 - c1)*Y] / b
```

### LM曲線（貨幣市場の均衡）

貨幣需要関数: `M/P = l1*Y - l2*r`

LM曲線（Y と r の関係）:
```
r = (l1*Y - M/P) / l2
```

## 均衡の解析解

IS曲線とLM曲線を連立して解くと:

```
Y* = (l2 * A + b * M/P) / (b*l1 + l2*(1 - c1))
r* = (l1 * Y* - M/P) / l2
```

ここで `A = c0 - c1*T + I0 + G`

## 出力

`steady_state` / `simulate` は以下のフィールドを持つ NamedTuple を返します。

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `Y` | `Float64` / `Vector{Float64}` | 均衡産出 |
| `r` | `Float64` / `Vector{Float64}` | 均衡利子率 |
| `C` | `Float64` / `Vector{Float64}` | 均衡消費 |
| `I` | `Float64` / `Vector{Float64}` | 均衡投資 |

`steady_state` はスカラー、`simulate` は長さ1のベクトルを返します。

## 基本的な使い方

```julia
using DME

# モデルのインスタンス化
m = ISLMModel(
    100.0,  # c0: 自律消費
    0.8,    # c1: 限界消費性向
    200.0,  # I0: 自律投資
    50.0,   # b:  投資の利子率感応度
    100.0,  # G:  政府支出
    100.0,  # T:  税
    0.2,    # l1: 貨幣需要の所得感応度
    100.0,  # l2: 貨幣需要の利子率感応度
    1000.0, # M:  マネーサプライ
    1.0,    # P:  物価水準
)

# 均衡の計算
eq = steady_state(m)
println("Y* = ", eq.Y)
println("r* = ", eq.r)
println("C* = ", eq.C)
println("I* = ", eq.I)

# SimulationResult に変換
sim = simulate(m)
result = to_simulation_result(m, sim, "equilibrium")

# 描画
plot_result(result, ["Y", "r", "C"])
```

## 政策ショックの比較

`DME.islm_policy_shock` を使うことで、ベースラインと政策後の均衡を一括比較できます。
返り値の `SimulationResult` はインデックス1がベースライン、インデックス2が政策後の値を持ちます。

```julia
# 財政拡張: G を100から150に増加
m_base   = ISLMModel(100.0, 0.8, 200.0, 50.0, 100.0, 100.0, 0.2, 100.0, 1000.0, 1.0)
m_fiscal = ISLMModel(100.0, 0.8, 200.0, 50.0, 150.0, 100.0, 0.2, 100.0, 1000.0, 1.0)

result = DME.islm_policy_shock(
    m_base, m_fiscal;
    scenario_names = ("baseline", "fiscal_expansion"),
)

println("ΔY = ", result["Y"][2] - result["Y"][1])
println("Δr = ", result["r"][2] - result["r"][1])

# 金融緩和: M を1000から1200に増加
m_monetary = ISLMModel(100.0, 0.8, 200.0, 50.0, 100.0, 100.0, 0.2, 100.0, 1200.0, 1.0)
result_m = DME.islm_policy_shock(
    m_base, m_monetary;
    scenario_names = ("baseline", "monetary_expansion"),
)
```

## 他モデルとの比較

| 項目 | IS-LM | Solow | Ramsey | RBC |
|------|-------|-------|--------|-----|
| 時間軸 | 静学 | 動学 | 動学 | 動学 |
| 最適化 | なし | なし | あり | あり |
| 貨幣 | あり | なし | なし | なし |
| 財政政策 | あり | なし | 一部 | 一部 |
| 分析対象 | 短期需要・政策効果 | 長期成長 | 最適蓄積 | 景気循環 |

## 限界

- **静学モデル**: 期待形成・資本蓄積・動学的調整を扱わない
- **価格硬直の前提**: 物価水準 `P` は固定されており、インフレや総供給の変化を分析できない
- **利子率**: 名目利子率のみ（実質利子率・インフレ期待は未考慮）
- **需要サイドのみ**: 総供給曲線（生産能力・労働市場）との統合は非対象
- **線形モデル**: 非線形な消費・投資行動は考慮しない
- **外生的貨幣供給**: 中央銀行の利子率ルール（テイラールール等）は非対象
