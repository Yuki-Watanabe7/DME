# AD-ASモデル

## 目的

AD-AS（総需要・総供給）モデルは、財市場・貨幣市場・労働市場を統合した静学マクロ経済モデルです。
物価水準 `P` と実質産出 `Y` を同時に内生的に決定し、**需要ショック**（財政政策・金融政策）と
**供給ショック**（技術変化・コスト変化・インフレ期待）の経済効果を分析します。

IS-LMモデルとの根本的な違いは、物価水準 `P` を固定しないことです。IS-LMでは物価が固定される
ため供給側の分析ができませんでしたが、AD-ASモデルでは総供給曲線（SRAS）を通じて物価と産出の
同時決定を扱います。

RBC・Ramseyモデルとは異なり、家計・企業の動学的最適化は扱いません。New Keynesian モデルへ
進む橋渡しとして位置づけられます。

## 変数

| 変数 | 説明 |
|------|------|
| `Y`  | 実質GDP（産出・所得） |
| `P`  | 物価水準 |
| `r`  | 名目利子率（AD曲線の背後にあるIS-LMから導出） |
| `C`  | 消費 |
| `I`  | 投資 |

## パラメータ・外生変数

### 総需要側（IS-LM由来）

#### 消費関数

| パラメータ | 説明 | 典型値 |
|-----------|------|--------|
| `c0`      | 自律消費 | 100.0 |
| `c1`      | 限界消費性向 MPC (0 < c1 < 1) | 0.8 |

#### 投資関数

| パラメータ | 説明 | 典型値 |
|-----------|------|--------|
| `I0`      | 自律投資 | 200.0 |
| `b`       | 投資の利子率感応度 (b > 0) | 50.0 |

#### 財政・外生変数

| 変数 | 説明 | 典型値 |
|------|------|--------|
| `G`  | 政府支出 | 100.0 |
| `T`  | 税（定額税） | 100.0 |

#### 貨幣市場

| パラメータ/変数 | 説明 | 典型値 |
|----------------|------|--------|
| `l1`           | 貨幣需要の所得感応度 (l1 > 0) | 0.2 |
| `l2`           | 貨幣需要の利子率感応度 (l2 > 0) | 100.0 |
| `M`            | 名目マネーサプライ | 300.0 |

### 総供給側

| パラメータ | 説明 | 典型値 |
|-----------|------|--------|
| `Y_n`     | 潜在産出（自然産出水準, Y_n > 0） | 1500.0 |
| `v`       | SRAS曲線の傾き（価格感応度: dY/dP, v > 0） | 500.0 |
| `P_e`     | 期待物価水準 (P_e > 0) | 1.0 |

## モデルの構造

### 総需要（AD）曲線

IS-LMモデルの均衡条件から、物価水準 `P` を所与としたときの産出 `Y` を導出する。

**IS曲線**（財市場の均衡）:
```
Y = c0 + c1*(Y - T) + I0 - b*r + G
```

**LM曲線**（貨幣市場の均衡）:
```
M/P = l1*Y - l2*r
```

IS・LMを連立して r を消去すると AD 曲線が得られる:
```
A = c0 - c1*T + I0 + G     （自律需要の切片）
D = b*l1 + l2*(1 - c1)     （共通分母、D > 0）

Y_AD(P) = (l2*A + b*M/P) / D
```

`P` が上昇すると実質貨幣供給 `M/P` が低下 → 利子率上昇 → 投資減少 → Y 低下。
したがって AD 曲線は右下がりになる。

### 短期総供給（SRAS）曲線

SRAS 曲線は期待物価 `P_e` のもとでの生産者行動を表す線形モデルで与える:

```
P_SRAS(Y) = P_e + (1/v) * (Y - Y_n)
```

同等に:
```
Y_SRAS(P) = Y_n + v*(P - P_e)
```

`v` は SRAS の平坦度を決める。`v → ∞` のとき SRAS は水平（ケインズ的）、
`v → 0` のとき SRAS は垂直（長期総供給 LRAS に対応）。

### 長期総供給（LRAS）

長期均衡では期待物価が実際の物価に一致（`P_e = P`）するため:
```
Y = Y_n  （すべての P について）
```

LRAS は `Y = Y_n` の垂直線。本モデルでは LRAS は参照概念として明示するが、
短期均衡（AD と SRAS の交点）が主な計算対象。

## 均衡の解析解

AD 曲線と SRAS 曲線を連立する:

```
(l2*A + b*M/P) / D = Y_n + v*(P - P_e)
```

両辺に P を掛けて整理すると P の2次方程式が得られる:

```
D*v*P² + [D*(Y_n - v*P_e) - l2*A]*P - b*M = 0
```

判別式 = `B² + 4*D*v*b*M > 0` が常に成立するため実数解が存在し、
正の根のみ経済的に意味を持つ:

```
B    = D*(Y_n - v*P_e) - l2*A
P*   = (-B + sqrt(B² + 4*D*v*b*M)) / (2*D*v)
Y*   = Y_n + v*(P* - P_e)
r*   = (l1*Y* - M/P*) / l2
C*   = c0 + c1*(Y* - T)
I*   = I0 - b*r*
```

## 出力

`steady_state` / `simulate` は以下のフィールドを持つ NamedTuple を返す。

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `Y` | `Float64` / `Vector{Float64}` | 均衡産出 |
| `P` | `Float64` / `Vector{Float64}` | 均衡物価水準 |
| `r` | `Float64` / `Vector{Float64}` | 均衡名目利子率（IS-LMと整合） |
| `C` | `Float64` / `Vector{Float64}` | 均衡消費 |
| `I` | `Float64` / `Vector{Float64}` | 均衡投資 |

`steady_state` はスカラー、`simulate` は長さ1のベクトルを返す。

## 基本的な使い方

```julia
using DME

m = ADASModel(
    100.0,  # c0: 自律消費
    0.8,    # c1: 限界消費性向
    200.0,  # I0: 自律投資
    50.0,   # b:  投資の利子率感応度
    100.0,  # G:  政府支出
    100.0,  # T:  税
    0.2,    # l1: 貨幣需要の所得感応度
    100.0,  # l2: 貨幣需要の利子率感応度
    300.0,  # M:  名目マネーサプライ
    1500.0, # Y_n: 潜在産出
    500.0,  # v:   SRAS傾き（価格感応度）
    1.0,    # P_e: 期待物価水準
)

# 均衡の計算
eq = steady_state(m)
println("Y* = ", eq.Y)
println("P* = ", eq.P)
println("r* = ", eq.r)

# SimulationResult に変換
sim = simulate(m)
result = to_simulation_result(m, sim, "equilibrium")
```

## ショック分析

`DME.adas_shock_compare` を使うことで、ベースラインとショック後の均衡を一括比較できる。

### 需要ショック（財政拡張）

```julia
m_base   = ADASModel(100.0, 0.8, 200.0, 50.0, 100.0, 100.0, 0.2, 100.0, 300.0, 1500.0, 500.0, 1.0)
m_demand = ADASModel(100.0, 0.8, 200.0, 50.0, 150.0, 100.0, 0.2, 100.0, 300.0, 1500.0, 500.0, 1.0)

result = DME.adas_shock_compare(m_base, m_demand; scenario_names = ("baseline", "fiscal_expansion"))
println("ΔY = ", result["Y"][2] - result["Y"][1])  # 正: Y上昇
println("ΔP = ", result["P"][2] - result["P"][1])  # 正: P上昇（需要増加によるインフレ）
```

### 供給ショック（正の技術ショック）

```julia
m_supply = ADASModel(100.0, 0.8, 200.0, 50.0, 100.0, 100.0, 0.2, 100.0, 300.0, 1600.0, 500.0, 1.0)
result_s = DME.adas_shock_compare(m_base, m_supply; scenario_names = ("baseline", "supply_improvement"))
println("ΔY = ", result_s["Y"][2] - result_s["Y"][1])  # 正: Y上昇
println("ΔP = ", result_s["P"][2] - result_s["P"][1])  # 負: P低下（供給増加によるデフレ圧力）
```

## ショックの比較

| ショック | AD曲線 | SRAS曲線 | Y の変化 | P の変化 |
|---------|--------|---------|---------|---------|
| 需要増加（G↑, M↑） | 右シフト | 不変 | 上昇 | 上昇 |
| 需要減少（G↓, M↓） | 左シフト | 不変 | 低下 | 低下 |
| 正の供給ショック（Y_n↑） | 不変 | 右シフト | 上昇 | 低下 |
| 負の供給ショック（Y_n↓, P_e↑） | 不変 | 左シフト | 低下 | 上昇 |
| スタグフレーション（P_e↑） | 不変 | 上方シフト | 低下 | 上昇 |

## IS-LMとの関係

AD-AS モデルの AD 曲線は IS-LM モデルそのものを内包している。

| 項目 | IS-LM | AD-AS |
|------|-------|-------|
| 物価 | 固定（外生） | 内生（SRAS で決定） |
| 供給ショック | 分析不能 | SRAS シフトで分析可能 |
| インフレ | 扱わない | 短期的に分析可能 |
| 財政・金融政策 | AD曲線の導出の背後 | AD シフトとして扱う |

## 他モデルとの比較

| 項目 | IS-LM | AD-AS | Solow | Ramsey | RBC |
|------|-------|-------|-------|--------|-----|
| 時間軸 | 静学 | 静学 | 動学 | 動学 | 動学 |
| 物価 | 固定 | 内生 | なし | なし | なし |
| 供給ショック | ✗ | ✓ | ✓ | ✓ | ✓ |
| 需要ショック | ✓ | ✓ | ✗ | 一部 | 一部 |
| 最適化 | なし | なし | なし | あり | あり |

## 限界

- **静学モデル**: 期間間の資本蓄積・期待形成の動学を扱わない
- **線形 SRAS**: 実際の供給側の非線形な調整を近似にとどめる
- **期待の外生性**: `P_e` は所与。期待の合理的形成や適応的期待は非対象
- **短期のみ**: 長期均衡への調整経路（SRAS の内生的シフト）は扱わない
- **需要側の仮定**: IS-LM と同じ線形の消費・投資関数を前提とする
- **名目利子率**: 実質利子率・フィッシャー方程式との整合は非対象
- **閉鎖経済**: 貿易・経常収支・為替レートは非対象
- **New Keynesian への橋渡し**: 完全な動学的一般均衡モデル（DSGE）へ進む際は
  NK モデルを参照すること
