## 2. 基準ユースケース

### 2.1 基準経済・頻度・分析ホライズン

| 項目 | 既定 | 根拠・注記 |
|---|---|---|
| 基準経済 | 米国 | hyperscaler・半導体・製造装置の主要主体が米国に集中し、FRED 経由で部門別系列を取得しやすい。日本その他は国固有系列・制度設定をモデル本体へ埋め込まず追加可能とする（[Keen 実証化戦略](keen_empirical_strategy.md) §1.1 と同方針） |
| 基準頻度 | 四半期（`Δt = 0.25` 年） | CAPEX・GDP・企業利益・雇用の公表頻度に整合。より高頻度の市場系列（信用スプレッド等）は四半期へ集約して用いる |
| ショック前の安定期間 | 8 四半期（`t = -8 … -1`） | ショック前の baseline 挙動が定常近傍で安定していることを確認するための助走区間。診断の起点は `t = 0` |
| ショック後の評価期間 | 20 四半期（`t = 0 … 19`） | 設備投資調整（数四半期）→ 雇用・所得（1〜2 年）→ 消費・総産出という波及の遅れを 5 年で覆う |
| 分析ホライズン合計 | 28 四半期 | 診断（§4）・判定問題（§3）はすべてこの区間の出力に対して評価する |
| ショック適用時点 | `t = 0` | 特記なき限り全シナリオ共通。複数イベントの時点差は §5.2 で指定する |

- **助走区間の契約**: `t = -8 … -1` で baseline からの乖離が生じてはならない。生じる場合は初期値が基準経路上にないことを意味し、診断を実行せず警告とする。
- 実データ履歴再生時の標本期間は本書では固定しない。必須系列の共通利用可能期間から決定論的に算出する方式を #170 で定める。

### 2.2 起点となる事象

初期MVPが起点として扱う事象を 3 種に限定する。

| ID | 事象 | モデル上の入力対象 | 初期MVPでの扱い |
|---|---|---|---|
| `E1` | AI 計算需要または収益期待の下方修正 | 期待変数（AI・クラウド部門の期待需要／期待収益） | **外生入力**。全ショックシナリオの共通起点 |
| `E2` | hyperscaler の CAPEX 計画縮小 | 計画 CAPEX（目標設備能力からの計画値、または計画値への直接介入） | **外生入力**。`E1` からの内生反応と、計画修正の外生上乗せを分離して指定する |
| `E3` | 半導体・関連設備需要の減速 | 半導体・製造装置部門の受注・受注残 | **内生を既定**（`E1`・`E2` の波及結果）。外生入力は感応度分析・履歴再生のみに用いる |

**契約**: `E3` を既定で外生入力にしない。`E1`・`E2` から `E3` が内生的に発生することが、本モデルが因果構造を持つことの最小条件であり、`E3` を外生で与えると Q1（§3）が自明に成立してしまう。

### 2.3 分析対象となる波及先

ロードマップ #125 の初期部門に対応する 5 部門を、本書の記号として固定する。部門境界の最終確定は #165。

| ID | 部門 | 本書で追跡する代表量 |
|---|---|---|
| `S1` | AI・クラウド需要部門 | 期待需要・計画 CAPEX・実行 CAPEX・キャンセル率 |
| `S2` | 半導体設計・製造 | 受注・受注残・出荷・在庫・稼働率・産出・投資 |
| `S3` | 製造装置・データセンター建設・電力関連 | 受注・受注残・産出・投資・雇用 |
| `S4` | 金融・信用 | 信用スプレッド・貸出態度・借換（ロールオーバー）条件・部門別債務残高・利払い負担 |
| `S5` | 家計・一般経済 | 雇用・賃金・所得・消費・部門別GDP寄与・総産出 |

- `S1`–`S3` を**関連産業内**、`S4` を**信用経路**、`S5` を**一般経済**と呼ぶ。この 3 区分が §3・§4 の判定で用いる集計単位である。
- 初期MVPでは各部門を**集約部門**として扱い、企業単位 ABM へ拡張しない（§6）。

### 2.4 表記

| 記号 | 意味 |
|---|---|
| `x_t` | 変数 `x` のシナリオ実行値（四半期 `t`） |
| `x_t^{base}` | 同一時点の baseline（`Sc0`）値 |
| `dx_t` | baseline 比乖離。水準変数は相対乖離 `(x_t - x_t^{base}) / x_t^{base}`、比率・金利・スプレッドは差分 `x_t - x_t^{base}`（単位は %pt / bp） |
| `peak(dx)` | 評価期間 `t = 0 … 19` における `dx_t` の絶対値最大値（符号を保持） |
| `H` | 評価期間長（既定 20 四半期） |

**契約**: 判定・診断はすべて `dx_t`（baseline 比）に対して行い、水準の絶対値では行わない。単位・季節調整・実質/名目の差がシナリオ間で相殺されるため。

## 3. 判定問題

初期MVPが回答する問いを 5 つに固定する。各問いは、シミュレーション出力から**真偽が一意に決まる関数**として書けることを要件とする。判定に用いる内生変数の生成方程式は #169、閾値の較正は #170 が定める。

以下の閾値はすべて**暫定既定値**であり、診断層の設定値として外部化する（§4.4）。

### Q1. CAPEX 調整が関連産業内の在庫・稼働率調整で収束する条件は何か

| 項目 | 内容 |
|---|---|
| 判定量 | 総産出乖離 `dY_t`、部門別産出乖離 `dY_{s,t}`、`S2`・`S3` の在庫比率・稼働率 |
| 判定条件 | 次を**すべて**満たすとき `contained_adjustment` と判定する。<br>(a) `|peak(dY)| ≤ 0.5%`<br>(b) `S5` の雇用・消費乖離がいずれも閾値未満（§4.2 の閾値）<br>(c) `S2`・`S3` の産出乖離が peak 後 8 四半期以内に peak の 50% 以下へ回復し、かつ回復が単調（8 四半期窓で再悪化しない）<br>(d) `S4` の信用スプレッド乖離が `+50bp` 未満 |
| 出力 | 診断ラベル（§4.3）、収束時点（(c) を満たした最初の `t`）、収束時の在庫比率・稼働率 |
| 「条件」の同定方法 | パラメータ・初期状態の 1 次元スイープ（§3 Q5 と共通）で `contained_adjustment` が成立する領域の境界を出力する。単一実行では「収束したか」しか答えられないため、Q1 の回答は**必ずスイープ結果**として提示する |
| 依存 | #165（在庫・稼働率の定義）・#169（調整方程式）・#171（診断 API） |

### Q2. 信用スプレッド・借換条件・貸出態度が悪化し、投資削減を増幅する条件は何か

| 項目 | 内容 |
|---|---|
| 判定量 | 増幅度 `A = |peak(dI^{full})| / |peak(dI^{credit-off})|`（`dI` は `S1`–`S3` 合計の実行 CAPEX 乖離） |
| 反実仮想の定義 | `credit-off` は、**同一シナリオ・同一ショック**を、投資関数の信用条件感応パラメータ（資本コスト・貸出態度・借換条件の各弾性）を `0` に固定して再実行したもの。ショック系列・初期状態・乱数は変えない |
| 判定条件 | `A ≥ 1.2` のとき「信用増幅あり」と判定する。`A` が定義できない（`peak(dI^{credit-off}) = 0`）場合は `indeterminate` とし、比を報告しない |
| 出力 | `A`、増幅の発現時点（`dI^{full}` と `dI^{credit-off}` の差が閾値を超えた最初の `t`）、スプレッド乖離の peak と時点 |
| 「条件」の同定方法 | 信用チャネル弾性・初期債務比率・利払いカバレッジのスイープに対する `A` の曲線を出力し、`A = 1.2` を横切る境界を報告する |
| 依存 | #166（債務残高更新式）・#169（投資関数・信用条件） |

**契約**: 増幅度は**同一実装内の反実仮想**でのみ定義する。信用チャネルを持たない別モデル（例: New Keynesian）との比較で代用しない（#167・[ADR 0006](../adr/0006-cross-model-reasoning-contract.md) の同名変数の非同一視）。

### Q3. 雇用・所得・消費を通じ、一般経済へ波及する条件は何か

| 項目 | 内容 |
|---|---|
| 判定量 | `S5` の雇用乖離 `dL_t`・実質可処分所得乖離 `dYD_t`・消費乖離 `dC_t`、および総産出乖離のうち消費経路が占める寄与シェア `share_C` |
| 判定条件 | 次を**すべて**満たすとき「家計経路による波及あり」と判定する。<br>(a) `peak(dL) ≤ -0.5%` かつ `peak(dC) ≤ -0.8%`<br>(b) `share_C ≥ 0.30`<br>(c) `dC_t` の悪化開始が `dI_t` の悪化開始より**後**（波及の向きが CAPEX → 消費であることの最小確認） |
| 寄与分解 | `share_C` は総産出乖離を最終需要項目別（`S1`–`S3` 直接需要・消費・その他）へ分解した寄与の比。分解方式は #169 で確定する。分解が定義できない場合は Q3 を `indeterminate` とし、`share_C` を報告しない |
| 出力 | `peak(dL)`・`peak(dC)`・`share_C`・各系列の悪化開始時点 |
| 依存 | #164（因果グラフの家計経路）・#166（所得・消費の会計）・#169（雇用・消費関数） |

### Q4. 金融緩和または需要回復により波及が遮断される条件は何か

| 項目 | 内容 |
|---|---|
| 判定量 | `Sc4`（緩和あり）と `Sc3`（緩和なし）の対比 |
| 判定条件 | 次のいずれかを満たすとき「遮断成功」と判定する。<br>(a) 診断ラベル（§4.3）が `Sc3` の `broad_downturn` から `Sc4` で `sectoral_downturn` 以下へ降格する<br>(b) `|peak(dY)|` が 30% 以上縮小し、かつ `dY_t` が閾値内へ回復する時点が 4 四半期以上前倒しになる |
| 出力 | 両シナリオの診断ラベル・`peak(dY)`・回復時点・緩和の適用時点と規模 |
| 「条件」の同定方法 | 緩和の**規模**と**適用時点（遅延）**の 2 次元スイープを出力し、遮断成功領域の境界を報告する。遅延が長いほど遮断効果が減衰することの確認を含む |
| 依存 | #168（政策イベントの適用時点規則）・#169（政策金利・金融条件の伝達） |

**契約**: Q4 の結果を政策提言・政策効果の因果推定として提示しない。モデル構造に条件付きの反実仮想比較であり、実際の政策効果の推定値ではない（§8・[llm_safety.md](../llm_safety.md)）。

### Q5. 同じ初期ショックでも経路が分岐する非線形性・閾値をどの変数で確認するか

| 項目 | 内容 |
|---|---|
| 分岐候補変数（初期MVPで必ず走査する） | (i) `S1`–`S3` の初期債務比率、(ii) 利払いカバレッジ比率、(iii) `S2`・`S3` の初期稼働率、(iv) 初期在庫比率、(v) `S4` の信用スプレッド感応パラメータ |
| 走査方法 | 各変数について 1 次元グリッドスイープ（他は既定値に固定）。同一ショック系列（`Sc2` または `Sc3`）を全格子点へ適用する |
| 閾値の検出条件 | 次のいずれかを満たす格子点区間を「閾値近傍」として報告する。<br>(a) 診断ラベル（§4.3）が隣接格子点間で切り替わる<br>(b) `|peak(dY)|` の隣接格子点間の変化が、同一スイープの中央値変化の 3 倍を超える |
| 出力 | 走査変数ごとの (格子値, 診断ラベル, `peak(dY)`, `A`) の表と、閾値近傍区間 |
| 判定不能の扱い | 全格子点で同一ラベルの場合は「本グリッド上では分岐を検出せず」と明示する。グリッドを拡張して分岐を作らない |
| 依存 | #169（非線形項の所在）・#170（分岐が数値解法の産物でないことの確認） |

**契約**: 閾値は**グリッド上で検出された近傍区間**として報告し、単一の臨界値として断定しない。数値解法の刻み幅・許容誤差に対する頑健性確認を #170 の検証項目に含める。

## 4. 「景気悪化」「景気後退」の操作的扱い

### 4.1 公式景気後退判定との区別

| 区分 | 内容 | 本モデルの扱い |
|---|---|---|
| **公式景気後退判定** | NBER Business Cycle Dating Committee 等による事後判定。委員会の裁量的判断、複数指標の総合評価、確定値・改定後データに基づき、判定公表は数か月〜1 年以上遅れる | **再現対象にも予測対象にもしない**。モデル出力を NBER 判定と一致させることを較正目標・評価指標にしない |
| **モデル上の広範な景気悪化** | 本モデルの内生変数が baseline 比で広く・深く・持続的に悪化した状態 | `broad_downturn` という**中立的なモデル内診断ラベル**として出力する（§4.3） |

**契約**:

- モデル出力に「景気後退（recession）」という語をラベル名・変数名・出力フィールド名として用いない。`broad_downturn` を用いる。
- 実データ履歴再生（#170）で過去の景気後退期と時期が一致した場合も、それは**モデル診断と公式判定の時期的一致**であり、公式判定の再現ではない。評価指標としては「一致した/しなかった」を記述的に報告するにとどめ、一致率を較正の目的関数にしない。
- 景気後退確率の一点推定を出力しない（§6）。

### 4.2 `broad_downturn` の操作的定義

**広がり（breadth）・深さ（depth）・持続性（persistence）**の 3 軸を、4 つの指標群で評価する。

**指標群**（各群は少なくとも 1 系列を持つ。系列の最終確定は #165）

| 群 | 系列 | 深さ閾値（baseline 比、暫定） |
|---|---|---|
| `G1` 総産出 | 総産出 / GDP proxy | `dY_t ≤ -1.0%` |
| `G2` 部門別実体活動 | 各部門の産出 `dY_{s,t}`・投資 `dI_{s,t}` | 産出 `≤ -3.0%` または 投資 `≤ -8.0%` |
| `G3` 家計 | 雇用 `dL_t`・実質可処分所得 `dYD_t`・消費 `dC_t` | 雇用 `≤ -0.5%`、所得 `≤ -0.8%`、消費 `≤ -0.8%` |
| `G4` 信用条件 | 信用スプレッド・貸出態度 | スプレッド `≥ +100bp`、または貸出態度指標が引き締め方向へ既定幅超 |

**持続性**: 各群の閾値超過が **2 四半期以上連続**すること。

**広がり**: 実体部門（`S1`・`S2`・`S3`・`S5`）のうち、産出乖離が `-1.0%` 以下となった部門の割合 `breadth ≥ 0.60`。

**判定ルール**

```
broad_downturn        := G1 が持続的に閾値超 かつ 4群中3群以上が持続的に閾値超 かつ breadth ≥ 0.60
sectoral_downturn     := (G2 が持続的に閾値超) かつ broad_downturn でない
contained_adjustment  := Q1 の (a)–(d) をすべて満たす（§3 Q1）
indeterminate         := 上記のいずれにも該当しない
```

**契約**:

- **単一四半期のマイナス成長のみで景気悪化と判定しない**。持続性条件（2 四半期以上連続）と広がり条件を必ず併課する。
- 成長率の連続 2 四半期マイナス（いわゆる technical recession）を判定基準に採用しない。baseline 比乖離の水準・広がり・持続性で評価する。
- `indeterminate` を `broad_downturn` へ寄せない。判定不能は判定不能として出力する（[ADR 0007](../adr/0007-sfc-integration-contract.md) の「不整合を自動補正せず構造化する」方針と同型）。

### 4.3 診断ラベルの階層と出力契約

| ラベル | 意味 | 排他性 |
|---|---|---|
| `contained_adjustment` | 関連産業内の在庫・稼働率調整で収束 | `broad_downturn`・`sectoral_downturn` と排他 |
| `sectoral_downturn` | 部門レベルの調整が閾値を超えるが、広がり・総産出条件を満たさない | `broad_downturn` と排他 |
| `broad_downturn` | 広がり・深さ・持続性の 3 条件を満たす | — |
| `indeterminate` | いずれの条件も満たさない、または判定に必要な系列が欠落 | — |

診断出力には、ラベルに加えて次を必ず含める（後続 Issue が構造を確定）。

- ラベル判定に使った各群の充足状況（群ごとの真偽・超過開始時点・超過継続四半期数）
- `breadth` の値と、悪化と判定された部門の一覧
- `peak(dY)` とその時点、回復時点（該当する場合）
- 用いた閾値セットの識別子とバージョン

### 4.4 閾値の外部化と感応度

- §4.2 の数値はすべて**暫定既定値**であり、モデル方程式へハードコードしない。診断層の設定値（閾値セット）として外部化し、識別子とバージョンを出力へ含める。
- 診断結果を提示する際は、**閾値を変えたときにラベルが変わるか**を必ず併記する。少なくとも各閾値を ±50% 変化させたときのラベルを報告する。
- 閾値感応度によりラベルが変わる場合、その事実を隠して単一ラベルのみを提示しない。

## 5. 比較シナリオ

### 5.1 必須シナリオセット

初期MVPで**必ず**実行・比較するシナリオを 5 つに固定する。

| ID | 名称 | 内容 | 含む起点事象 |
|---|---|---|---|
| `Sc0` | `baseline` | ショックなし。基準経路 | — |
| `Sc1` | `expectation_only` | AI 需要期待のみ下方修正 | `E1` |
| `Sc2` | `expectation_capex` | AI 需要期待下方修正 + CAPEX 計画削減 | `E1` + `E2` |
| `Sc3` | `capex_credit` | 上記 + 信用スプレッド拡大 | `E1` + `E2` + 信用ショック |
| `Sc4` | `capex_credit_easing` | 上記 + 金融緩和 | `E1` + `E2` + 信用ショック + 政策緩和 |

**入れ子（nested）契約**: `Sc1 ⊂ Sc2 ⊂ Sc3 ⊂ Sc4` とし、下位シナリオのショックは上位シナリオでも**同一の意味・単位・時点・持続期間・規模**で適用する。追加分のみが差分となる。

- これにより `Sc2 - Sc1` = CAPEX 計画削減の追加効果、`Sc3 - Sc2` = 信用ショックの追加効果、`Sc4 - Sc3` = 緩和の効果（Q4）として解釈できる。
- 入れ子性が破れる変更（例: `Sc3` だけ `E1` の規模を変える）は禁止する。必要な場合は別 ID のシナリオとして追加する。

### 5.2 各ショックの指定必須項目

各ショックは、後続 Issue が追加の理論判断なしに実装できるよう、次の 7 項目を**すべて**指定する。指定のないショックは実装対象としない。

| 項目 | 内容 |
|---|---|
| `target` | 適用先のモデル変数（期待需要・計画 CAPEX・信用スプレッド・政策金利 等） |
| `meaning` | 経済的な意味（何が起きたことを表すか） |
| `unit` | 単位（%・%pt・bp・水準比 等）と、水準ショックか比率ショックかの別 |
| `sign` | 符号の向きと、悪化方向がどちらか |
| `timing` | 適用開始時点（四半期）。既定は `t = 0` |
| `shape` | 時間形状（`step` / `ramp` / `AR1_decay`）と形状パラメータ |
| `duration` | 持続期間（四半期）。`AR1_decay` の場合は半減期で指定 |

### 5.3 ショック定義（暫定既定値）

以下の規模・形状は**暫定既定値**であり、実データ整合による較正は #170 で行う。本節が固定するのは「何を指定しなければならないか」と「シナリオ間で共有される定義」であり、数値そのものではない。

| ショック | `target` | `meaning` | `unit` | `sign` | `timing` | `shape` | `duration` | 暫定規模 |
|---|---|---|---|---|---|---|---|---|
| `SH-EXP` (`E1`) | `S1` 期待需要（または期待収益） | AI 計算需要・収益期待の下方修正 | baseline 比 % | 負（下方修正） | `t = 0` | `AR1_decay`（半減期 6 四半期） | 恒久（減衰） | `-10%` |
| `SH-CAPEX` (`E2`) | `S1` 計画 CAPEX | hyperscaler の CAPEX 計画縮小（期待経由の内生反応に**上乗せ**する計画修正） | baseline 比 % | 負 | `t = 0` | `step` → 4 四半期後から `ramp` で解消 | 8 四半期 | `-15%` |
| `SH-CREDIT` | `S4` 信用スプレッド | 社債スプレッド拡大・借換条件悪化・貸出態度引き締め | bp | 正（拡大＝悪化） | `t = 1` | `AR1_decay`（半減期 4 四半期） | 恒久（減衰） | `+150bp` |
| `SH-EASING` | 政策金利 / 金融条件 | 金融緩和 | %pt | 負（引き下げ） | `t = 2` | `step` | 8 四半期 | `-100bp` |

**時点差の根拠（暫定）**: `SH-CREDIT` を `t = 1` とするのは、信用条件の悪化が期待・計画修正の**後**に生じる構図を既定とし、`E1`・`E2` と信用ショックの識別を可能にするため。`SH-EASING` を `t = 2` とするのは、政策反応が信用悪化の観測後に生じることを表す。両時点は Q4 のスイープ対象であり、固定値ではない。

**契約**:

- `SH-CAPEX` は、`SH-EXP` からの内生的な CAPEX 反応に**上乗せする外生の計画修正**として定義する。内生反応の再指定ではない。この区別が失われると `Sc1` と `Sc2` の差分が解釈できなくなる。
- 同一時点に複数ショックが適用される場合の順序・合成規則は #168 で定める。本書の既定値は時点をずらすことで初期MVPでは順序問題を回避する。
- すべてのシナリオは、同一の初期状態・同一のパラメータセット・同一の数値解法設定で実行する。差は入力ショックのみとする。

### 5.4 追加シナリオの扱い

必須セット以外のシナリオ（需要回復シナリオ、CAPEX 削減が長期化するシナリオ 等）は追加してよいが、次を満たすこと。

- `Sc0`–`Sc4` の定義を変更しない。
- §5.2 の 7 項目をすべて指定する。
- 必須セットとの関係（どのシナリオの派生か）を明示する。

## 6. 初期MVPの対象外

| 対象外 | 理由 | 代替として提供するもの |
|---|---|---|
| 個別企業の株価予測 | 本モデルは集約部門モデルであり、企業固有の評価・裁定を表現しない | 部門レベルの利益・資本コスト・信用条件の経路 |
| 景気後退確率の一点推定 | 確率を出すにはショックの確率分布・モデル不確実性の定量化が必要で、初期MVPの識別可能性を超える | 診断ラベル（§4.3）と、閾値・パラメータ感応度（§4.4・Q5） |
| 数千社規模の ABM | 因果構造と会計整合性の検証が先。異質性は責務境界を残したうえで段階的に追加する（#125 の後段） | 集約部門モデル + 部門内異質性の将来拡張余地 |
| 世界全体の国際波及 | 米国基準の閉じた構造で判定問題を解けることを先に確認する | 国別拡張が可能な設定分離（§2.1） |
| AI 技術進歩そのものの内生化 | 技術進歩の内生化は別種のモデル（内生成長）であり、CAPEX 循環の判定問題に不要 | AI 需要・収益期待を外生ショックとして扱う（`E1`） |
| 投資推奨・自動売買 | DME の LLM 層の禁止事項（[llm_safety.md](../llm_safety.md)） | シナリオ比較・因果経路・感応度の記述 |
| 非公開企業・銀行データを前提とした較正 | 再現不能な較正はリポジトリの再現性契約に反する | 公開系列・proxy による限定較正（#170） |

**契約**: 後続 Issue は、本節の対象外項目を実装対象へ含めない。含める必要が生じた場合は本書を改訂し、判定問題・シナリオ・検証基準への影響を明記する。

## 8. 限界

本書が固定する契約自体の限界を明記する。

1. **判定問題は「モデル内での条件」を問う**。Q1–Q5 の回答は、本モデルの構造と較正に条件付きの結果であり、現実経済における条件の推定値ではない。
2. **閾値は理論から導かれていない**。§4.2 の数値は暫定既定値であり、較正後も「この値を超えたら景気悪化」という実体的な意味を持たない。感応度の併記（§4.4）が必須なのはこのためである。
3. **`broad_downturn` は公式景気後退の代理指標ではない**。時期的一致があっても、判定基準・データ vintage・判断過程が異なる（§4.1）。
4. **反実仮想（Q2 の `credit-off`、Q4 の緩和有無）は構造の一部を無効化した実行であり**、現実の政策効果・チャネル寄与の因果推定ではない。
5. **集約部門モデルは、部門内の異質性に起因する非線形性を表現しない**。実際の連鎖倒産・特定企業の資金繰り断絶などは初期MVPの範囲外（§6）。
6. **本書は実データによる検証を経ていない**。ショック規模・時点差・部門粒度の妥当性は #170 の履歴再生で初めて評価される。

LLM による説明生成時は、上記を [llm_safety.md](../llm_safety.md) の必須記載事項と併せて提示する。
