# New Keynesian 3方程式モデル

## 目的

New Keynesian (NK) 3方程式モデルは、現代のマクロ経済分析・金融政策分析の標準的なフレームワークです。
**産出ギャップ `x`・インフレ率 `π`・名目利子率 `i`** の3変数を、以下の3本の線形方程式で同時に決定します。

1. **動学的IS曲線** — 需要側：産出ギャップと実質金利の関係
2. **New Keynesian Phillips Curve (NKPC)** — 供給側：インフレと産出ギャップの関係
3. **Taylor Rule** — 金融政策：中央銀行の利子率設定ルール

IS-LMやAD-ASとの根本的な違いは、**前向き期待（forward-looking expectations）** を明示的に扱う点です。
家計・企業が将来の経済状態を合理的に予測し、それが現在の意思決定に反映されます。

Phase 5以降の実データ接続やPhase 6以降のLLM解釈への橋渡しとして位置づけられます。

## 変数

| 変数 | 説明 |
|------|------|
| `x`  | 産出ギャップ（実際の産出と潜在産出の乖離） |
| `π`  | インフレ率 |
| `i`  | 名目利子率 |

IRF（インパルス応答関数）の返り値はすべて**定常状態からの乖離**として表現されます。

## パラメータ

### IS曲線

| パラメータ | 説明 | 典型値 |
|-----------|------|--------|
| `σ`       | 異時点間代替弾力性（σ > 0, 大きいほどIS曲線が平坦） | 1.0 |
| `r_n`     | 自然実質利子率（r_n > 0） | 0.02 |

### New Keynesian Phillips Curve

| パラメータ | 説明 | 典型値 |
|-----------|------|--------|
| `β`       | 割引因子（0 < β < 1） | 0.99 |
| `κ`       | NKPC傾き（κ > 0, 産出ギャップ→インフレの感応度） | 0.1 |

### Taylor Rule

| パラメータ | 説明 | 典型値 |
|-----------|------|--------|
| `φ_π`     | インフレ反応係数（φ_π > 1: Taylor principle） | 1.5 |
| `φ_x`     | 産出ギャップ反応係数（φ_x ≥ 0） | 0.5 |
| `π_star`  | インフレ目標 | 0.02 |

### ショック持続性

| パラメータ | 説明 | 典型値 |
|-----------|------|--------|
| `ρ_x`     | 需要ショックの持続性（0 ≤ ρ_x < 1） | 0.8 |
| `ρ_c`     | コストプッシュショックの持続性（0 ≤ ρ_c < 1） | 0.5 |
| `ρ_m`     | 金融政策ショックの持続性（0 ≤ ρ_m < 1） | 0.5 |

## モデルの構造

### 動学的IS曲線

前向き期待を持つオイラー方程式から導出されます：

```
x_t = E_t[x_{t+1}] - (1/σ)(i_t - E_t[π_{t+1}] - r_n) + ε_x,t
```

- `E_t[...]` : t 期時点での合理的期待
- `ε_x,t` : 需要ショック（AR(1)過程: ε_x,t = ρ_x * ε_x,{t-1} + u_x,t）
- 実質金利 `r_t = i_t - E_t[π_{t+1}]` が産出ギャップに影響
- IS-LMとの違い: 期間間の代替効果を明示的に扱う

### New Keynesian Phillips Curve

価格改定の摩擦（Calvo pricing）から導出されます：

```
π_t = β * E_t[π_{t+1}] + κ * x_t + ε_c,t
```

- `ε_c,t` : コストプッシュショック（AR(1)過程: ε_c,t = ρ_c * ε_c,{t-1} + u_c,t）
- AD-ASのSRASとの違い: インフレ期待が**前向き**（将来のインフレへの期待が現在のインフレを動かす）
- `κ` は価格粘着性（price stickiness）の指標。κ → ∞ で完全な価格伸縮性

### Taylor Rule

中央銀行の利子率設定ルール：

```
i_t = r_n + π_star + φ_π * (π_t - π_star) + φ_x * x_t + ε_m,t
```

- `ε_m,t` : 金融政策ショック（AR(1)過程: ε_m,t = ρ_m * ε_m,{t-1} + u_m,t）
- **Taylor principle**: `φ_π > 1` のとき一意安定均衡が存在する（インフレが上昇すれば実質金利も上昇）
- `φ_π < 1` のとき均衡が不定（indeterminate）になる場合がある

## 解法：Minimum State Variable (MSV) 解

### 行列表現

定常状態からの乖離（x̃ = x, π̃ = π - π_star）に対してTaylor ruleを代入すると：

```
A * [x̃_t, π̃_t]' = B * E_t[[x̃_{t+1}, π̃_{t+1}]'] + d_t
```

```
A = [[1 + φ_x/σ,  φ_π/σ],    B = [[1,  1/σ],
     [-κ,          1    ]]         [0,  β   ]]
```

### MSV 解

ショック ε_t が AR(1)（E_t[ε_{t+1}] = ρ * ε_t）のとき、MSV解は：

```
[x̃_t, π̃_t]' = (A - ρ*B)^{-1} * d * ε_t
```

各ショックのベクトル `d`：

| ショック | d ベクトル |
|---------|-----------|
| 需要ショック（ε_x） | `[1, 0]'` |
| コストプッシュショック（ε_c） | `[0, 1]'` |
| 金融政策ショック（ε_m） | `[-1/σ, 0]'` |

名目利子率の乖離：
```
ĩ_t = φ_π * π̃_t + φ_x * x̃_t [+ ε_m,t（金融政策ショックのみ）]
```

## 定常状態

すべてのショックがゼロのとき：

```
x* = 0          （産出はポテンシャルに一致）
π* = π_star     （インフレは目標値）
i* = r_n + π_star（名目利子率 = 自然実質利子率 + インフレ目標）
```

## 出力

`steady_state` は以下の NamedTuple を返す：

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `x` | `Float64` | 産出ギャップ（= 0） |
| `π` | `Float64` | インフレ率（= π_star） |
| `i` | `Float64` | 名目利子率（= r_n + π_star） |

`impulse_response` は定常状態からの乖離の時系列を返す：

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `x` | `Vector{Float64}` | 産出ギャップの変化 |
| `π` | `Vector{Float64}` | インフレ率の変化（π_star からの乖離） |
| `i` | `Vector{Float64}` | 名目利子率の変化（i* からの乖離） |

## 基本的な使い方

```julia
using DME

m = NewKeynesianModel(
    1.0,   # σ:      異時点間代替弾力性
    0.02,  # r_n:    自然実質利子率
    0.99,  # β:      割引因子
    0.1,   # κ:      NKPC傾き
    1.5,   # φ_π:    インフレ反応係数（Taylor principle: φ_π > 1）
    0.5,   # φ_x:    産出ギャップ反応係数
    0.02,  # π_star: インフレ目標
    0.8,   # ρ_x:    需要ショック持続性
    0.5,   # ρ_c:    コストプッシュショック持続性
    0.5,   # ρ_m:    金融政策ショック持続性
)

# 定常状態
ss = steady_state(m)
println("x* = ", ss.x)      # 0.0
println("π* = ", ss.π)      # 0.02
println("i* = ", ss.i)      # 0.04

# インパルス応答（需要ショック）
irf = impulse_response(m, 1.0; shock = :demand, T = 20)
println("需要ショック t=1: x=", irf.x[1], " π=", irf.π[1], " i=", irf.i[1])

# SimulationResult に変換して可視化
result = to_simulation_result(m, irf, "irf_demand")
p = plot_result(result; vars = ["x", "π", "i"], title = "NK Model: 需要ショックのIRF")
```

## ショック分析

### 需要ショック（ε_x > 0）

```julia
irf = impulse_response(m, 1.0; shock = :demand, T = 20)
# irf.x[1] > 0  産出ギャップ上昇
# irf.π[1] > 0  インフレ上昇
# irf.i[1] > 0  中銀が利上げ（Taylor rule に従って）
```

### コストプッシュショック（ε_c > 0）

```julia
irf = impulse_response(m, 1.0; shock = :cost_push, T = 20)
# irf.π[1] > 0  インフレ上昇（スタグフレーション的）
# irf.x[1] < 0  産出ギャップ低下（中銀の利上げによる需要抑制）
# irf.i[1] > 0  名目利子率上昇
```

### 金融政策ショック（予期せぬ利上げ: ε_m > 0）

```julia
irf = impulse_response(m, 1.0; shock = :monetary, T = 20)
# irf.x[1] < 0  産出ギャップ低下
# irf.π[1] < 0  インフレ低下
# irf.i[1] > 0  名目利子率上昇
```

## Taylor ruleパラメータ変更の比較

```julia
# タカ派（積極的なインフレ抑制）vs ハト派
m_hawk = NewKeynesianModel(1.0, 0.02, 0.99, 0.1, 2.0, 0.5, 0.02, 0.8, 0.5, 0.5)  # φ_π=2.0
m_dove = NewKeynesianModel(1.0, 0.02, 0.99, 0.1, 1.5, 0.5, 0.02, 0.8, 0.5, 0.5)  # φ_π=1.5

# コストプッシュショックに対する反応を比較
result = DME.nk_irf_compare(m_dove, m_hawk;

    scenario_names = ("dovish (φ_π=1.5)", "hawkish (φ_π=2.0)"),

# タカ派: インフレ影響が小さい（abs(π_alt[1]) < abs(π_base[1])）

```

## ショックの経済効果サマリー

| ショック | IS曲線 | NKPC | x の変化 | π の変化 | i の変化 |
|---------|--------|------|---------|---------|---------|
| 需要ショック（ε_x↑） | 右シフト | 不変 | 上昇 | 上昇 | 上昇 |
| コストプッシュ（ε_c↑） | 不変 | 上方シフト | 低下 | 上昇 | 上昇 |
| 金融政策（ε_m↑, 利上げ） | 左シフト（実質金利上昇） | 不変 | 低下 | 低下 | 上昇 |

## 線形近似と限界

本実装は**線形化されたNKモデル**です。以下の点に注意してください。

### 線形近似
- すべての方程式は定常状態周りで対数線形近似されています
- 大きなショック（>10%程度）に対しては精度が低下する可能性があります
- 非線形な制約（ZLB: zero lower bound 等）は扱いません

### 非対象項目
- **ゼロ金利制約 (ZLB)**: 名目利子率の非負制約なし
- **非線形解法**: 完全非線形の解は非対象（log-linearization のみ）
- **開放経済**: 貿易・為替レート・資本移動は非対象
- **本格的なDSGE推定**: カリブレーションのみ（最尤推定・ベイズ推定は非対象）
- **異質な主体（HA-HANK）**: 代表的主体モデルのみ
- **財政政策の動学**: Taylor ruleのみ扱い、財政政策ルールは非対象
- **実データによるパラメータ推定**: 非対象

### MSV解の存在条件
`(A - ρ*B)` が正則行列である必要があります。これは通常、Taylor principle (`φ_π > 1`) が満たされる標準的なパラメータ設定で成立します。`φ_π ≤ 1` の場合は均衡が不定になる可能性があります。
