## 2. テキスト決定木：どのモデルを選ぶか

```
分析の主眼は？
│
├─ 長期成長・定常状態
│   ├─ 貯蓄率を外生として扱ってよい → Solow
│   └─ 家計の最適化から貯蓄率を内生化したい → Ramsey
│
├─ 景気循環・短期変動
│   ├─ 実物ショック（技術・生産性）が主役 → RBC
│   ├─ 物価・インフレを扱いたい
│   │   ├─ 物価は固定でよい（直感的な財政・金融政策分析）
│   │   │   ├─ 物価水準を内生化したい（需給ショック分析）→ AD-AS
│   │   │   └─ 物価を固定し財政・金融政策の直感を見たい → IS-LM
│   │   └─ 前向き期待・インフレ動学・Taylorルール → New Keynesian
│   └─ 開放経済・為替・海外金利 → Mundell-Fleming
│
└─ データ駆動・実証的分析
    └─ 複数変数の線形動学を係数から直接シミュレーション → VAR
```

## 4. 各モデルの概要・代表的ショック・限界

### 4.1 Solow 成長モデル

**得意なこと**
- 長期的な経済成長と定常状態（黄金律資本）の決定
- 人口成長率・技術進歩率・貯蓄率の変化が定常値に与える影響
- 収束仮説（異なる初期資本をもつ国が同一定常状態に収束する）の確認

**代表的な問い**
- 「貯蓄率を高めると長期的な資本と生産はどう変わるか？」
- 「技術進歩がなければ成長は止まるか？」

**限界**
- 貯蓄率が外生（最適化なし）なので政策分析に使いにくい
- 確率的ショックがない（景気循環分析には不向き）
- 物価・金融政策・労働市場を扱えない

**詳細**: [Solow モデル解説](models/solow.md)

---

### 4.2 Ramsey 最適成長モデル

**得意なこと**
- 消費平準化と最適な資本蓄積経路の内生的決定
- 割引因子・資本分配率が定常状態と移行経路に与える影響
- Solow を拡張した「なぜ貯蓄するのか」の理論的根拠

**代表的な問い**
- 「家計が無限期間にわたって効用を最大化するとき、最適な消費・貯蓄経路はどうなるか？」
- 「初期資本が定常値より低い場合、どのように定常状態へ収束するか？」

**限界**
- 労働供給が非弾力的（固定）→ 労働市場の分析には不向き
- 確率的ショックがない → 景気循環の定量分析には不向き
- 物価・金融政策を扱えない

**詳細**: [Ramsey モデル解説](models/ramsey.md)

---

### 4.3 RBC モデル（リアル・ビジネス・サイクル）

**得意なこと**
- 全要素生産性（TFP）ショックが景気循環を引き起こすメカニズムの解明
- 産出・消費・投資・労働・賃金・利子率のインパルス応答関数（IRF）
- 弾力的な労働供給と資本蓄積を通じた実物的伝播

**代表的ショック**
- 正の技術ショック（TFP 1% 上昇）→ 産出・消費・投資・労働が同時増加

**限界**
- 名目硬直性・金融摩擦がない → 金融政策・インフレ分析には不向き
- 労働市場の摩擦を扱えない
- 実証的には過大な労働変動を示すことが多い

**詳細**: [RBC モデル解説](models/rbc.md)

---

### 4.4 IS-LM モデル

**得意なこと**
- 財政政策（G・T 変化）と金融政策（M 変化）の産出・利子率への短期効果
- クラウディングアウト効果・流動性のわなの直感的説明
- 教育・入門的な政策分析

**代表的な問い**
- 「財政拡大は利子率を上昇させてどれだけ民間投資を押し退けるか？」
- 「マネーサプライを増やすと産出と利子率にどう影響するか？」

**限界**
- 静学モデル（動学的調整を扱えない）
- 物価固定 → インフレ・供給ショック分析には不向き
- 前向き期待がない → 将来政策の効果を分析できない
- 開放経済を扱えない

**詳細**: [IS-LM モデル解説](models/islm.md)

---

### 4.5 AD-AS モデル

**得意なこと**
- 需要ショック（財政・金融政策）と供給ショック（コスト・技術）の物価・産出への同時効果
- スタグフレーション・インフレ加速の直感的説明
- IS-LM（需要側）と総供給曲線（供給側）の橋渡し

**代表的ショック**
- 政府支出増加（AD シフト右）→ 産出増・物価上昇
- 石油価格上昇（AS シフト左）→ 産出減・物価上昇（スタグフレーション）

**限界**
- 静学モデル（動学的な期待・調整過程を扱えない）
- 前向き期待がない
- インフレ動学（フィリップス曲線の動学的側面）は New Keynesian に譲る
- 開放経済を扱えない

**詳細**: [AD-AS モデル解説](models/adas.md)

---

### 4.6 New Keynesian 3方程式モデル

**得意なこと**
- インフレ・産出ギャップ・名目利子率の同時決定と動学
- Taylor ルールによる中央銀行の政策金利設定
- 前向き合理的期待の明示的な取り扱い
- 需要ショック・コストプッシュショックのIRF

**代表的ショック**
- 需要ショック（IS曲線シフト）→ 産出ギャップ拡大・インフレ上昇
- コストプッシュショック（NKPC シフト）→ インフレ上昇・産出ギャップ縮小
- 金融政策ショック（Taylor ルールの乖離）

**限界**
- 高度に線形化・集計された3方程式モデルであり、家計・企業の異質性を扱えない
- 金融摩擦・信用制約を扱えない
- 開放経済版には Mundell-Fleming または開放 DSGE が必要

**詳細**: [New Keynesian モデル解説](models/new_keynesian.md)

---

### 4.7 Mundell-Fleming モデル（小国開放経済）

**得意なこと**
- 変動・固定為替相場制のもとでの財政・金融政策効果の比較
- 海外金利ショック（r* 変化）が為替・産出に与える影響
- 外需ショック（純輸出の自律的変化）の分析
- UIP（金利平価）を通じた為替レートの内生的決定

**代表的ショック**
- 変動相場制 × 財政拡大 → クラウディングアウト（為替高）で効果ゼロ
- 変動相場制 × 金融緩和 → 為替安 → 純輸出増 → 効果大
- 固定相場制 × 財政拡大 → 産出増（乗数効果）

**限界**
- 静学モデル（動学的な期待・資本フローの速度を扱えない）
- 物価固定（小国標準仮定）
- 大国の場合は世界利子率への影響を無視できない

**詳細**: [Mundell-Fleming モデル解説](models/mundell_fleming.md)

---

### 4.8 VAR モデル（簡易ベクトル自己回帰）

**得意なこと**
- 複数の経済変数の線形動学を係数行列から直接シミュレーション
- 変数間の波及経路・IRF の確認
- 理論モデルと実証の橋渡し（係数を OLS 推定値に差し替えやすい）

**代表的な問い**
- 「GDP・インフレ・利子率が相互にどのように影響し合うか？」
- 「ある変数への1単位ショックが他変数に与えるIRFはどうか？」

**限界**
- 現実装は係数手入力の簡易 VAR(1)（データからの推定は将来対応予定）
- 構造識別なし（どのショックが何かは別途識別戦略が必要）
- 理論的解釈が乏しい（経済学的根拠のあるモデルと比較して）

**詳細**: [VAR モデル解説](models/var.md)

## 5. 利用上の注意とモデル組み合わせ例

### 複数モデルの組み合わせ

単一のモデルでは答えられない問いに対して、複数モデルを補完的に使うことが有効な場合がある。

| 問い | 推奨する組み合わせ |
|---|---|
| 「金融緩和の長期・短期効果を両方知りたい」 | IS-LM（短期・直感）+ Ramsey（長期・定常） |
| 「技術ショックの景気循環と長期成長への影響」 | RBC（循環・IRF）+ Solow（長期収束） |
| 「インフレと為替を同時に扱いたい」 | New Keynesian（インフレ動学）+ Mundell-Fleming（為替効果）※別々に分析 |
| 「理論と実証を比較したい」 | RBC または New Keynesian（理論）+ VAR（実証） |

### モデル選択の原則

1. **問いを絞る**: 問いが広すぎるとどのモデルも答えを出せない。「何を内生化したいか」を明確にする。
2. **静学か動学か**: 定常状態の「水準」を知りたいなら静学で十分。「どのように変化するか」を知りたいなら動学が必要。
3. **物価を扱うか**: 物価・インフレが問いに含まれるなら IS-LM は不適切。AD-AS または New Keynesian を選ぶ。
4. **開放経済か**: 為替・海外金利が問いに含まれる場合は Mundell-Fleming が唯一の選択肢（現在）。
5. **理論 vs. 実証**: 経済理論的な解釈を重視するなら Ramsey/RBC/New Keynesian。データ適合を重視するなら VAR。

### LLM エージェントへの注意事項

- このガイドは 2026年6月時点のモデル実装に基づいている。
- 各モデルの実装詳細・API は個別の [モデル解説ドキュメント](models/) を参照すること。
- 実データ接続の詳細や LLM による自動モデル選択はこのガイドの対象外。
- 表中の「任意」はモデルの制約による上限なく変数定義可能（VAR）または対応する概念が存在しないことを示す。
