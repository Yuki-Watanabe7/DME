# 日本マクロデータ接続 設計方針

> 関連 Issue: #63
> 状態: 設計方針（BOJ・内閣府等の接続は未実装。e-Stat・FRED 接続は実装済み）

---

## 1. 背景と目的

日本のマクロ経済分析には、日本銀行・内閣府・財務省・総務省・厚生労働省など複数の統計機関のデータが必要である。
しかし、取得形式・系列体系・更新頻度・ライセンス表記がデータソースごとに異なるため、いきなり実装に入るとスコープが膨らみやすい。

本ドキュメントは、日本マクロデータ接続の対象・優先順位・取得方法・前処理課題を整理し、後続の実装 Issue への分解可能な状態にすることを目的とする。

---

## 2. e-Stat 接続との役割分担

既存の e-Stat 接続（`EStatClient`）との役割分担を最初に整理する。

| 項目 | e-Stat 接続 | 本ドキュメントで検討する接続 |
|------|------------|---------------------------|
| カバー範囲 | 政府統計の総合窓口（多省庁の統計を横断取得） | 各機関の独自 API・CSV・公表資料 |
| 主な強み | 統一 API・系列コードでの一括取得 | リアルタイム性・機関独自系列・詳細粒度 |
| 金融系データ | 弱い（BOJ 系は少ない） | 強い（BOJ 時系列統計が主力） |
| GDP・SNA | 一部収録（公表遅れあり） | 内閣府 SNA が一次ソース |
| API 有無 | あり（e-Stat API） | 機関ごとに異なる（下表参照） |

### 2.1 e-Stat で代替可能な系列

以下の系列は e-Stat API 経由でも取得可能であり、**e-Stat 接続を優先使用**する。

| 系列 | e-Stat 統計表 ID | 備考 |
|------|----------------|------|
| 消費者物価指数（CPI） | 0003427113 | 総務省。e-Stat 経由が容易 |
| 完全失業率 | 0003307059 | 総務省・労働力調査。e-Stat 経由が容易 |
| 総人口 | 0003445078 | 総務省・人口推計 |
| 家計消費支出 | 0003343671 | 総務省・家計調査 |

### 2.2 e-Stat では不十分な系列

以下の系列は e-Stat では取得できないか、更新の遅れ・粒度の制約が大きく、**各機関の一次ソース接続が必要**。

| 系列 | 理由 |
|------|------|
| 政策金利（無担保コール翌日物） | BOJ 時系列統計が一次ソース。e-Stat に収録なし |
| 長期金利（国債利回り） | BOJ 時系列統計が一次ソース |
| 為替レート（USD/JPY 等） | BOJ 時系列統計が一次ソース |
| 実質 GDP・SNA 系列 | 内閣府 SNA の CSV が一次ソース（e-Stat の速報性が低い） |
| 産出ギャップ | 内閣府 HP 公表の Excel のみ |
| 貿易収支 | 財務省・国際収支統計が一次ソース |

## 3. データソース候補の整理

### 3.1 日本銀行（BOJ）

**BOJ 時系列統計システム**（https://www.stat-search.boj.or.jp/）は日本の金融・外為データの事実上の一次ソースである。

| 項目 | 内容 |
|------|------|
| 提供形式 | Web UI からの CSV ダウンロード、**検索 API**（非公式仕様） |
| API 有無 | 非公式 API あり（`https://www.stat-search.boj.or.jp/ssi/` エンドポイント）。公式 API 仕様の公開はない |
| 更新頻度 | 日次・月次・四半期（系列による） |
| ライセンス | 「出所：日本銀行」の明記が必要。商用利用・再配布は要確認 |
| 主な制約 | 公式 API の仕様が非公開のためスクレイピングに準じた取得となる。レート制限の明文化なし |

**主要系列候補**:

| 系列名 | 系列コード例 | 頻度 | 優先度 |
|--------|------------|------|--------|
| 無担保コール翌日物金利（政策金利） | FM01'MADR'ZP（実効値）| 月次 | P1 |
| 10 年国債利回り（新発） | FM08'MADR'ZP | 月次 | P1 |
| USD/JPY 為替レート（月中平均） | FM01'MZSP'Z2（インターバンク中心相場） | 月次 | P1 |
| M2（マネーストック） | MD01'MZSA'M2 | 月次 | P2 |
| 日銀当座預金残高 | FM01'MZSS'F1B | 月次 | P3 |

> **注意**: BOJ の系列コードは版によって変更されることがある。取得時は系列検索 UI で最新コードを確認すること。

**取得方針**:
- 短期的には CSV 手動ダウンロードを `DataSeries` に読み込むアダプタを実装
- 中期的には非公式 API ラッパーを `BojClient` として実装（FRED/e-Stat に準じたインターフェース）

---

### 3.2 内閣府 SNA（国民経済計算）

**内閣府の国民経済計算**（https://www.esri.cao.go.jp/jp/sna/）は GDP・消費・投資等の一次ソースである。

| 項目 | 内容 |
|------|------|
| 提供形式 | **Excel / CSV ダウンロード**（速報・確報の都度公表）。API なし |
| API 有無 | **なし**。手動ダウンロードまたは scraping 対応が必要 |
| 更新頻度 | 四半期（速報：約 2 ヶ月後、確報：約 9 ヶ月後） |
| ライセンス | 「出典：内閣府」の明記が必要。政府統計データは著作権法上の保護を受けるが二次利用は概ね可能 |
| 主な制約 | ファイル URL・シート構成が公表のたびに変わりやすい。長期系列は「長期遡及データ」を別途ダウンロードする必要がある |

**主要系列候補**:

| 系列名 | 提供ファイル | 頻度 | 優先度 |
|--------|------------|------|--------|
| 実質 GDP（季節調整済み・年率換算） | 四半期別 GDP（2次速報等） | 四半期 | P1 |
| 名目 GDP | 同上 | 四半期 | P2 |
| 実質民間最終消費支出 | 同上 | 四半期 | P2 |
| 実質民間固定資本形成 | 同上 | 四半期 | P2 |
| 産出ギャップ | 内閣府推計（HP上のExcel）| 四半期 | P2 |
| 実質民間資本ストック | 資本ストック統計（年次） | 年次 | P3 |

**取得方針**:
- e-Stat 経由での取得を最初に試みる（内閣府 SNA は e-Stat に部分収録あり）
- e-Stat で不足する最新期・細粒度は CSV ダウンロードアダプタで補完
- API がないため、ファイル URL の固定化（バージョン管理）と fixture によるテスト対応が必須

---

### 3.3 財務省

**財務省の国際収支統計・国債金利情報**（https://www.mof.go.jp/）が主要データ源。

| 項目 | 内容 |
|------|------|
| 提供形式 | CSV / Excel ダウンロード。API なし |
| API 有無 | なし |
| 更新頻度 | 月次（国際収支：約 2 ヶ月後）、国債金利は日次 |
| ライセンス | 「出典：財務省」の明記が必要 |
| 主な制約 | ファイル形式が年度によって変わることがある。国際収支統計は日本銀行との共同公表のため BOJ 経由でも取得可能 |

**主要系列候補**:

| 系列名 | 提供資料 | 頻度 | 優先度 |
|--------|---------|------|--------|
| 貿易収支（財貿易）| 国際収支統計（BOJ 共同公表）| 月次 | P2 |
| 経常収支 | 同上 | 月次 | P3 |
| 国債流通利回り（10年） | 国債金利情報（日次 CSV）| 日次/月次 | P2 |

> **注意**: 長期金利（10 年国債利回り）は BOJ 時系列統計の月次データで代替可能であるため、財務省の日次データは高頻度分析が必要な場合に優先使用する。

**取得方針**:
- 貿易収支・経常収支は BOJ 時系列統計経由での取得を優先（同一データを BOJ も公表）
- 財務省独自系列（国債残高等）が必要になった場合に CSV アダプタを追加

---

### 3.4 総務省統計局

**総務省の消費者物価指数・労働力調査**は e-Stat 経由で取得可能であるため、本プロジェクトでは**原則として e-Stat 接続を使用**する。

| 系列 | 取得方法 | 備考 |
|------|---------|------|
| 消費者物価指数（CPI） | e-Stat API（既存） | 統計表 ID: 0003427113 |
| コア CPI（生鮮食品除く） | e-Stat API | 分類コード指定が必要 |
| 完全失業率 | e-Stat API（既存） | 統計表 ID: 0003307059 |
| 就業者数・労働参加率 | e-Stat API | 統計表 ID を確認して追加 |

**総務省直接接続は不要**。e-Stat が一次窓口として機能している。

---

### 3.5 厚生労働省

実質賃金・総実労働時間など労働系統計の一部は e-Stat 経由で取得できるが、最新速報は厚生労働省 HP の Excel 公表が先行することがある。

| 系列 | 取得方法 | 備考 |
|------|---------|------|
| 現金給与総額（名目賃金指数） | e-Stat 経由（毎月勤労統計調査）| 統計表 ID を確認して追加 |
| 実質賃金指数 | e-Stat 経由（CPI デフレート後）| 前処理で計算 |
| 総実労働時間 | e-Stat 経由（毎月勤労統計調査）| 統計表 ID を確認して追加 |

**優先度は P3**。P1・P2 系列が安定してから対応する。

## 5. データライセンス・出所表示方針

### 5.1 各機関の出所表示要件

| 機関 | 必要な表示 | 備考 |
|------|----------|------|
| 日本銀行 | 「出所：日本銀行」または「資料：日本銀行」 | BOJ HP 利用規約に基づく。商用利用は個別確認 |
| 内閣府 | 「出典：内閣府」 | 政府統計。二次利用可だが出典明記が必要 |
| 財務省 | 「出典：財務省」 | 同上 |
| 総務省（e-Stat 経由）| 「出典：総務省統計局」または e-Stat 表示ルールに従う | e-Stat API 利用規約参照 |
| 厚生労働省（e-Stat 経由）| 「出典：厚生労働省」 | 同上 |

### 5.2 DME での実装方針

- `DataSeries.source` に機関名を設定する（例: `"BOJ"`, `"ESRI"`, `"MOF"`）
- `DataSeries.metadata` に出所 URL・系列コード・取得日時を格納する
- LLM が生成するレポートには必ず出所を引用する（`docs/llm_safety.md` の禁止表現ルール参照）
- 商用利用・外部公開時は各機関の利用規約を個別確認すること

### 5.3 source フィールドの命名規則

| 機関 | `DataSeries.source` | 例 `DataSeries.id` |
|------|-------------------|--------------------|
| 日本銀行 | `"BOJ"` | `"BOJ_MZSP_Z2"` |
| 内閣府（国民経済計算） | `"ESRI"` | `"ESRI_RGDP_SA"` |
| 財務省 | `"MOF"` | `"MOF_TRADE_BALANCE"` |
| 総務省（e-Stat 経由） | `"e-Stat"` | `"ESTAT_0003427113"` |
| 厚生労働省（e-Stat 経由）| `"e-Stat"` | `"ESTAT_MNLABOR_001"` |

## 6. 前処理上の主な課題

| 課題 | 内容 | 対応策 |
|------|------|--------|
| 頻度の不一致 | GDP は四半期、金利・為替は月次 | `to_quarterly()` で集計してからモデルに渡す |
| 季節調整の有無 | 実質 GDP は季節調整済みだが、一部系列は原系列のみ | 季節調整済み系列を優先。未調整は `metadata` に記録 |
| 改訂・遡及変更 | SNA ベンチマーク改訂で過去値が変わる | 取得日時を `metadata` に記録。比較時は同一基準で取得 |
| ファイル URL の変更 | 内閣府 CSV は公表のたびに URL が変わりやすい | fixture 管理 + 手動更新ワークフローで対応 |
| 系列コードの変更 | BOJ 系列コードは見直しで変更されることがある | コード → 系列名の対応表をドキュメント管理 |
| 長期データの接続 | 制度変更・定義変更で系列が断絶することがある | 断絶点を `metadata` に記録し、LLM に伝達 |
| 単位・スケールの差 | モデル変数は正規化済み・実データは実単位 | キャリブレーションなし比較を禁止（variable_mapping.md 参照） |

## 7. 最小実装範囲の提案

日本マクロデータ接続の最小実装スコープを以下のとおり提案する。

### 7.1 最小実装の方針

- **BOJ 時系列統計 CSV アダプタ**を最初の実装対象とする
  - 理由: P1 系列（政策金利・長期金利・為替）の全てが BOJ ソース
  - CSV ダウンロードファイルを `DataSeries` に変換する `BojCsvLoader` を実装
  - fixture モード対応（`test/fixtures/boj/` に CSV を格納）
- **内閣府 GDP（e-Stat 経由）** を第二の実装対象とする
  - 理由: e-Stat 接続が既に存在するため、系列コードの追加のみで対応可能
  - e-Stat 統計表 ID の確認・fixture 追加・ドキュメント更新

### 7.2 最小実装でカバーする系列（P1 相当）

| 系列 | 接続方法 | 実装単位 |
|------|---------|---------|
| 政策金利（無担保コール翌日物） | BOJ CSV アダプタ | `BojCsvLoader` |
| 10 年国債利回り | BOJ CSV アダプタ | 同上 |
| USD/JPY 為替レート | BOJ CSV アダプタ | 同上 |
| 実質 GDP（季節調整済み） | e-Stat 系列追加 or CSV アダプタ | 系列 ID 追加 |

### 7.3 最小実装の対象外（後続 Issue へ分解）

- 内閣府 SNA CSV の自動取得（URL が変わりやすいため手動運用）
- 財務省系列の接続
- 厚生労働省系列の接続
- BOJ 非公式 API ラッパー（`BojClient`）の完全実装
- BIS 実効為替レートの接続
