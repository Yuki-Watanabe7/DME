# ADR 0001: Minsky系金融不安定性モデルの初版として Keen モデルを採用する

- **ステータス**: 採用
- **日付**: 2026-07-16
- **関連Issue**: #99（ロードマップ）・#100（候補調査・比較）
- **関連ドキュメント**: [Minsky系金融不安定性モデル 設計方針](../models/minsky_design.md)

## コンテキスト

DME に Minsky の金融不安定性仮説（FIH）に基づく動学マクロ金融モデルを追加するにあたり（#99）、
実装候補として以下の 3 系統を調査・比較した（比較表・詳細は設計方針ドキュメント参照）。

1. **Keen モデル**: Goodwin 成長循環に企業債務を導入した 3 変数 ODE 系（Keen 1995、Grasselli & Costa Lima 2012）
2. **Ryoo モデル**: 短期循環と Minsky 的長期波動を統合した 6〜7 変数 ODE 系（Ryoo 2010）
3. **Godley-Lavoie (SFC) モデル**: 部門間の会計整合性を核とする離散時間の大規模連立方程式体系（Godley & Lavoie 2007）

## 決定

**Keen モデル（Grasselli & Costa Lima 2012 定式化、状態変数 `ω`・`λ`・`d` の 3 変数 ODE 系）を
DME 初版の Minsky 系モデルとして採用する。**

## 理由

1. **最小の実装複雑度**: 状態変数 3・パラメータ約 10。固定刻み RK4 の自前実装で解けるため
   新規依存パッケージが不要で、均衡値も閉形式で求まる。
2. **FIH の中核メカニズムを再現**: 利潤 → 投資 → 債務蓄積のフィードバックによる内生循環と、
   良い均衡・債務崩壊（債務デフレ）の双安定性を最小構成で表現できる。
3. **数値検証のアンカーがある**: Grasselli & Costa Lima (2012) の均衡閉形式・安定性条件・数値例に対して、
   既存モデルと同水準の数値検証テストを書ける。
4. **後続機能への接続が自然**: Hedge / Speculative / Ponzi 判定や金融不安定性指標を
   `π`・`r d`・`κ(π)` の大小関係から直接定義できる。
5. **既存アーキテクチャとの親和性**: 低次元動学モデルとして `AbstractMacroModel`
   インターフェースに自然に適合する（統合設計は #101 で行う）。

## 見送りとした選択肢

- **Ryoo モデル**: 状態変数・パラメータ数が初版スコープを超え、数値検証のアンカーとなる
  標準的解析が薄い。資産価格を扱う後続拡張の第一候補とする。
- **Godley-Lavoie (SFC)**: 会計行列基盤の新設が必要で方程式規模も桁違い。
  将来的な発展として検討し、Keen モデル実装をその足掛かりとする。

## 影響

- 後続で Keen モデルの統合設計（#101）・実装 Issue を起こす。実装は連続時間 ODE の
  数値積分（固定刻み RK4）を含むが、`Project.toml` への依存追加は発生しない見込み。
- 資産価格バブルや部門間資金フローを扱う問いは初版ではスコープ外となり、
  Ryoo 型拡張・SFC 導入まで持ち越される。
