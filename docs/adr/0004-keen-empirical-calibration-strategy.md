# ADR 0004: Keen モデル実証化は米国基準・ODE residual 識別・固定/推定パラメータ分離を初版方式とする

- **ステータス**: 採用
- **日付**: 2026-07-18
- **関連Issue**: #99（ロードマップ）・#119（実証化の測定・識別・時系列整列方針の設計）
- **前提ADR**: [ADR 0001](0001-minsky-model-selection.md)（Keen モデル採用）・[ADR 0002](0002-minsky-integration-design.md)（Keen 統合方式）・[ADR 0003](0003-minsky-financing-regime-diagnostics.md)（診断層の分離）
- **関連ドキュメント**: [Keen モデル 実証化の測定・識別・時系列整列方針](../models/keen_empirical_strategy.md)

## コンテキスト

ADR 0001〜0003 で採用・統合・診断化した Keen モデル（連続時間 3 変数 ODE 系、状態変数 `ω`・`λ`・`d`、
貸出金利パラメータ `r`）を、次の段階で実データへ接続する。しかし次の困難がある。

1. モデル変数と統計系列は厳密には同一でなく、公表系列には**指数と比率が混在**する
   （例: FRED `PRS85006173` の labor share は指数）。
2. Keen は**時間単位が年**である一方、候補系列は月次・四半期が混在する。
3. **10 個の構造パラメータを少数の短い観測系列から同時推定**することは識別上困難であり、
   双安定 ODE のため軌跡当てはめは崩壊経路への跳びで不安定になりやすい。

測定・単位変換・頻度整列・固定/推定パラメータの分離を先に確定しないまま実装すると、
見かけ上の当てはまりだけを追う再現不能な推定になりやすい。本 ADR はこれを避けるため、
後続実装が追加の理論判断なしに着手できる初版方式を確定する。

## 決定

1. **初版の基準経済を米国とし、国別系列差はモデル本体へ埋め込まず観測データ設定・measurement metadata で分離する。**
   FRED / `FredClient` で主要系列を取得しやすいため。日本は同一の観測方程式・変換契約への
   拡張対象として設計する。`KeenModel`・`keen_rhs`・`steady_state` は無変更。

2. **観測方程式は「指数か比率か・部門範囲・季節調整・基準年を検証してから」採用し、指数系列を水準シェアとして直接使わない。**
   `ω` は名目比率での直接構成を推奨し、`PRS85006173` の指数を用いる場合は基準年水準へアンカーして比率化する。
   `λ` は `%` を `[0,1]` へ統一、`d` は `% of GDP` を比率へ、`r` は名目/実質化方式を区別し
   国債実質金利を企業借入金利と同一視しない。

3. **年単位 ODE と四半期観測を `Δt = 0.25` で整合させる時間軸契約を採る。**
   共通頻度は四半期。四半期ラベルを数値時間 `year + (n-1)*0.25` に変換して inner join し、
   四半期値を年次格子へ 4 点詰め込まない。月次→四半期の集計方法（平均/期末/合計）は系列ごとに固定し、
   欠損を `0` へ変換せず暗黙補完もしない。初版は確報値（非 vintage）を対象とする。

4. **固定パラメータと推定パラメータを分離し、全 10 パラメータ同時推定を既定にしない。**
   `α, β, δ, ν, r`（および投資曲率 `κ2`）を外部情報・文献値・標本統計で固定し、
   行動パラメータの最小集合（既定は Phillips `φ0, φ1` と投資 `κ0, κ1`）のみを限定的に推定する。

5. **識別戦略は ODE residual 方式を初版に採用する（trajectory・moment matching は不採用）。**
   観測状態の差分と `keen_rhs` の残差を方程式単位で最小化する。境界・符号制約、スケール差の重み付け、
   欠損/発散/状態域逸脱の objective 除外、弱識別・複数局所解の検出、再現性 metadata
   （methodology version `keen-empirical/1.0.0`）を設計に含める。

6. **検証は in-sample/out-of-sample、literature/calibrated、診断仮定感応度を分離して評価し、当てはまりを危機予測・因果推論と同一視しない。**
   RMSE/MAE/correlation に加え方向性・転換点・regime 遷移・発散有無を分けて評価する。

## 理由

- **基準経済の分離（決定 1）**: 国別差を metadata に閉じることで、ADR 0002・0003 の
  「モデル本体を無変更に保つ」責務境界を実証層でも維持できる。日本追加時も観測設定の差し替えで済む。
- **指数/比率の検証義務（決定 2）**: 指数（例: 2012=100）を `ω ∈ [0,1]` とみなすと `ω > 1` 等の
  非整合が生じ、以降の `π = 1 - ω - r d`・推定がすべて汚染される。検証を設計契約にすることで
  受け入れ条件「指数か比率かを検証せず直接利用しない」を構造的に満たす。
- **`Δt = 0.25` 契約（決定 3）**: 年単位 ODE に四半期値を年次格子へ詰め込むと時間スケールが 4 倍ずれ、
  成長率・差分がすべて過大評価される。数値時間軸での inner join は文字列順ソートの誤結合も防ぐ。
- **固定/推定分離（決定 4）**: 短い標本から 10 パラメータを同時推定すると弱識別・過剰適合になる。
  観測しやすい成長・減耗・資本産出比を固定し、行動パラメータのみを最小集合で推定することで
  識別性と再現性を確保する。
- **ODE residual の採用（決定 5）**: 双安定 ODE では trajectory 方式の目的関数が崩壊経路への跳びで
  不連続・初期値依存になり、最適化が不安定。moment matching は moments 不足で弱識別。
  ODE residual は方程式単位に分解でき目的関数が滑らかで、双安定性の罠を避けられる。
- **fit と危機予測の分離（決定 6）**: Minsky モデルの主眼は「内生的な不安定化の機序」であり、
  当てはまりの良さは危機の予測精度・因果関係・危機発生確率を意味しない。
  [LLM 安全性ルール](../llm_safety.md) の断定禁止とも整合する。

## 見送りとした選択肢

- **日本を初版基準経済にする**: fixture / live 経路の整備度で米国が先行するため後回し。
  観測方程式・変換契約は日本へそのまま拡張できる設計とする。
- **全 10 パラメータ同時推定**: 短い標本での弱識別・過剰適合を招くため既定にしない。
  識別性が確認できた場合の**将来オプション**として、methodology version を上げて拡張する。
- **trajectory 方式（軌跡当てはめ）**: 双安定 ODE で目的関数が不連続・初期値依存になり不安定。
  差分近似誤差を許容してでも ODE residual を優先する。将来、崩壊経路を除外した区間限定の
  trajectory 検証を補助的に加える余地は残す。
- **moment matching 方式**: moments がパラメータ数に対し不足し弱識別になるため主方式にしない。
- **vintage / リアルタイムデータでの初版推定**: データ整備コストが高く、初版は確報値を対象とする。
  リアルタイム分析は将来対応予定。

## 影響

- 後続実装 Issue は [実証化戦略](../models/keen_empirical_strategy.md) §2〜§6 の観測方程式・時間軸契約・
  推定設計を追加の理論判断なしに実装できる。実装先は実データ層（`src/data/`）と新規の実証・推定
  ユーティリティであり、`KeenModel` 本体・`keen_rhs`・診断層は無変更の見込み。
- `to_quarterly` の期末（`:end`）集計を要する系列を採用する場合は、前処理ユーティリティへの
  `method=:end` 追加が別途必要（[実証化戦略](../models/keen_empirical_strategy.md) §4.2）。
- methodology version `keen-empirical/1.0.0` を基準とし、観測方程式・変換規則・識別戦略・
  固定/推定分離を変更する際はバージョンを上げて provenance を保つ。
- 実データによる推定・検証の具体結果、日本系列の最終実装、複合スコア・危機確率の類は
  引き続き対象外とする。
